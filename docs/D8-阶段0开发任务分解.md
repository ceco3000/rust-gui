## 1. 任务分解方法

- 每项任务 ≤ 3 个工作日，有明确验收标准
- 优先级：P0（阻塞）> P1（核心）> P2（增强）> P3（发布——框架可运行时）
- 人力假设：1 全职 + 1 兼职贡献者

### 9.14 四次审计补充任务（CJK 文字渲染实验发现）

> **来源：** 2026-06-18 CheckBox 组件中文标签渲染实验。当前仅嵌入 Inter（拉丁字体），中文等 CJK 字符通过 `load_system_fonts()` 由 cosmic-text 塑形使用系统字体（macOS PingFang SC），但 Vello 渲染时 `draw_glyphs()` 使用的 `FontData` 硬编码为 Inter，导致 glyph ID 与塑形字体不匹配（显示为 `.notdef` ① 或空白）。

> **根因：** Vello 0.9 `draw_glyphs()` API 仅支持单字体 `FontData`，无法支持多字体混合渲染。完整方案需（1）Vello 升级至支持 atlas-based 字形纹理渲染；或（2）实现 per-glyph 字体路由，将塑形时使用的字体数据传递到渲染端。两者均需跨 `rgui-render` + `rgui-core` 的架构变更，超出阶段 0 范围。
