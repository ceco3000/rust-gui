## 2. 各阶段要点

### D3 — 从零 scaffold
- 5-crate workspace 骨架 + 核心 trait 契约（WidgetSpec/AppMessage/PersistState 签名点位，`todo!()`/最小定义）。
- 阶段 0 范围：保留薄 facade `rgui`；不含样式系统 `.rgss` 解析；组件 = Accordion+WaBadge；不做拖放；单一 vello；剔除 script/Rhai/devtools/skia。
- 验收：`cargo check --workspace` 通过；lint 克制（仅 `unsafe_code=deny`）；增量编译（改 `core::state` → 不重编 render）。

### D4 — 核心循环 + 状态 + 布局（TDD）
- WidgetSpec 核心循环（view/update/paint）+ WidgetRegistry + WidgetNode，跑通最小闭环。
- StateStore + diff(Patch/apply_patch) + snapshot（纯 Rust 单测）。
- LayoutEngine 封装 taffy（LayoutStyle → Taffy Style）。
- 最小示例运行：一个组件渲染到目标。

### D5 — 渲染管线（vello 离屏）【P0 清零】
- `rgui-render/backend/vello.rs` Vello 离屏渲染；`SceneGraph` draw 指令（从 WidgetView 转换）；`GlyphKey/GlyphAtlas/TextShaper` 字形 + cosmic-text。
- `vello-backend` feature 门控；单一 vello，不预留 skia。
- 验收：离屏像素断言；43 测试全绿；core 防火墙；SceneGraph 纯度；全仓零 unsafe。遗留 P1（from_view 占位、手工 rect）→ D6。

### D6 — 真实 from_view 转换 + 布局应用
- 补全 `from_view(WidgetView)`：递归转换 → SceneGraph；完整 Props 映射（Color/Size/Str/Int 等，不再静默忽略）；文本路径接入。
- **布局应用**：from_view 生成 SceneGraph 时调 LayoutEngine，让布局真正作用于渲染。
- 像素级端到端验证（替换 D5 手工 rect）。

### D7 — 窗口 + 事件循环（winit surface）【首帧时序修复】
- `rgui-platform` window/event_loop + 渲染到窗口。
- **P2-1 嵌套布局坐标累加（已修）**。
- 首帧时序修复（`ControlFlow::Poll` + `about_to_wait` 每帧 `request_redraw`）后窗口弹出即稳定渲染。

### D8 — 收敛窗口逻辑进 rgui-platform
- 把 window_demo 直接 winit/wgpu 的窗口创建 + 事件循环 + surface 渲染收敛进 `rgui-platform`（补齐 greenfield §C.3）。
- window_demo / facade 走 platform 公共 API，源码无直接 `winit::`/`wgpu::`。

### D9 — facade 入口统一 + 文本字形 + 按需重绘
- `rgui::App::run()` 实现（用户统一入口，内部走 `rgui_platform` + `rgui_render`）。
- cosmic-text 真实字形（替换矩形近似块）。
- 按需重绘（`about_to_wait` 改为有变更/脏才重绘，CPU 下降；保留首帧）。
- facade 残留 `dep:winit/dep:wgpu` 清理（经 platform/render re-export）。

### D10 — Accordion/WaBadge 组件 + 真实交互 demo
- `Accordion`（折叠/展开 + 点击交互 → update → view 更新 → 重绘）、`WaBadge`（整数 label）。
- `App::run` 暴露 config（标题/尺寸）。
- 窗口显示 Accordion + WaBadge，点击切换展开/收起（截图验证交互）；45 测试全绿。
