## 每份文档的要求

每份设计文档应满足以下最低要求：

1. **明确的设计目标**：本文档解决什么问题，不解决什么问题
2. **前置阅读**：列出必须先读的文档
3. **数据结构定义**：关键 struct/enum/trait 的完整 Rust 定义（不是伪代码）
4. **接口契约**：public API 的签名、前置条件、后置条件、错误处理策略
5. **与其他子系统的交互时序**：用序列图或编号步骤描述跨子系统流程
6. **边界情况处理**：空状态、错误状态、极限数据量下的行为
7. **验证标准**：如何判断设计是否正确实现（可测试的判定条件）
