## 1. 定位

`rgui` 是一个面向桌面的 Rust GUI 框架，在 greenfield 低复杂度重构后收敛为 **5 个 crate**。设计总则：

1. **一个能力，一条路径，一个归属**。凡不被当前阶段需要的能力一律不做。
2. **数据/状态层零 GPU、零平台依赖**（Cargo 依赖防火墙强保证）。
3. 文档是代码的唯一权威依据；文档与代码必须一致，不一致即判不通过。

## 2. Crate 拓扑（5 个，已与 `Cargo.toml` members 对齐）

| # | crate | 实责 | 纳入/来源 | 依赖方向 |
|---|-------|------|-----------|----------|
| 1 | `rgui-core` | 逻辑核心：组件模型 / 状态 / 布局 / 样式 / 组件 / 无障碍树 | 原 core + state + layout + style + components + a11y 树 | 零 GPU / 零平台 / 零 cssparser |
| 2 | `rgui-render` | 渲染引擎（单一 vello 后端） | 原 render | 只依赖 `rgui-core` |
| 3 | `rgui-platform` | 窗口 / 输入 / IME / 焦点（winit 隔离） | 原 platform | 只依赖 `rgui-core` |
| 4 | `rgui-macros` | 过程宏（WidgetSpec/AppMessage/PersistState + html!） | 原 macros | 仅 proc-macro 基础设施 |
| 5 | `rgui` | 顶层门面（facade）：重导出 + 启动协调 | 原 facade 瘦身 | 依赖全部 4 个 |

依赖防火墙（硬约束 A，已由 `rgui-core/Cargo.toml` 实证）：`rgui-core` 的 `[dependencies]` 不得出现 `rgui-render` / `rgui-platform` / `rgui-macros` / `winit` / `wgpu` / `vello` / `cosmic-text` 任一。当前 `rgui-core` 仅依赖可选的 `taffy`（纯 Rust 布局）——**防火墙成立**。

## 3. 依赖 DAG（有向无环，禁止反向边）

| 从 crate | 到 crate | 规则 |
|----------|----------|------|
| `rgui-core` | （无） | 只被依赖；**禁止**依赖 render/platform/macros |
| `rgui-render` | `rgui-core` | 唯一向下边；**禁止** `rgui-render → rgui-platform` |
| `rgui-platform` | `rgui-core` | 唯一向下边；**禁止** `rgui-platform → rgui-render` |
| `rgui-macros` | （无运行时 crate） | 只依赖 proc-macro 基础设施；生成代码给 core 用 |
| `rgui` (facade) | `rgui-core` / `rgui-render` / `rgui-platform` / `rgui-macros` | facade 依赖全部，仅重导出 + 启动协调 |

不变量：图为**有向无环图（DAG）**，无横向依赖、无环。

## 4. 核心 trait 契约

> 以下签名取自当前 `rgui-core/src/traits.rs`，与 greenfield §B.1 对齐；**实际实现中确定的差异已在字段/注释中标注**。

### 4.1 `AppMessage`

```rust
pub trait AppMessage: Send + Sync + 'static + fmt::Debug + Clone {
    fn message_name(&self) -> &'static str;
}
```

- 规则：所有跨边界传递的消息必须满足此 trait。
- 方法 `message_name()` 返回稳定消息名（用于日志/调试/序列化）。
- 内置实现：`rgui_core::NoopMsg`（`message.rs` 定义，`message_name()` 返回 `"noop"`）。

### 4.2 `PersistState`

```rust
pub trait PersistState: Send + Sync + 'static {
    fn schema_name() -> &'static str where Self: Sized;
    fn schema_version() -> u32 where Self: Sized;
    fn as_any(&self) -> &dyn Any;
    fn as_any_mut(&mut self) -> &mut dyn Any;
}
```

- 规则：组件/应用状态必须满足此 trait 以便快照与恢复。
- **当前实现状态**：`erased_serde::Serialize` 超级绑定尚未加入（在 D6/D7 引入序列化时按契约补全）；当前仅保留 `Any` 上下转型能力作为最小可用签名。

### 4.3 `WidgetSpec`（统一 Tier 1，无第二组件路径）

```rust
pub trait WidgetSpec: Send + Sync + 'static {
    type State: PersistState;
    type Message: AppMessage;

    fn name(&self) -> &'static str;
    fn view(&self, state: &Self::State, ctx: &ViewContext) -> WidgetView<Self::Message>;
    fn update(&self, msg: Self::Message, state: &mut Self::State, ctx: &mut UpdateContext);
    fn measure(&self, state: &Self::State, constraints: BoxConstraints, ctx: &MeasureContext) -> Size;
    fn paint(&self, state: &Self::State, bounds: Rect, ctx: &mut PaintContext);
    fn focusable(&self) -> bool { false }   // D12：默认不可获焦，组件可覆盖（Tab 导航/焦点切换）
    fn accessibility(&self, _s: &Self::State, _c: &AccessContext) -> AccessibilityNode {
        AccessibilityNode::none()
    }
}
```

- 规则：一个 widget 由关联状态类型与消息类型定义，提供 view/update/measure/paint 生命周期；`accessibility` 默认返回 `AccessibilityNode::none()`。
- **当前实现状态**：方法体为最小 stub（`todo!()` 或空实现），阶段 0 不实现业务逻辑；`#[derive(WidgetSpec)]` 宏当前**透传输入**（见 `rgui-macros`）。

### 4.4 `EventResult`

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum EventResult<M> {
    Handled,
    Prevented,
    Continue(M),
}
```

- 语义：`Handled` = 已处理，停止传播；`Prevented` = 被阻止（防默认行为）但仍传播；`Continue(M)` = 继续传播并携带派生消息 `M`。
- **实际差异**：greenfield §B.1 为无派生 trait；实际 `EventResult` 派生 `Debug, Clone, PartialEq, Eq`（测试可比较）。

## 5. 核心数据 / 值类型（`rgui-core`）

| 类型 | 定义（实际） | 说明 |
|------|------------|------|
| `WidgetId` | `pub struct WidgetId(pub u64)` | 组件唯一标识 |
| `NodeHandle` | `pub struct NodeHandle(pub u64)` | 节点句柄 |
| `WindowId` | `pub struct WindowId(pub u64)` | 窗口标识 |
| `Point` / `Size` / `Rect` | `geometry` | 几何类型（完整样式枚举在实现阶段补全） |
| `BoxConstraints` | `geometry` | 布局约束 |
| `Color` | `pub struct Color { pub r: u8, pub g: u8, pub b: u8, pub a: u8 }` | sRGB 存储；`Color::rgba()` / `Color::rgb()` 构造器。**实际用 u8，非 greenfield 设计的 f32** |
| `PropValue` | `enum { Unit, Bool(bool), Int(i64), Float(f64), Str(String), Color(Color) }` | 属性值。**实际无 `WidgetId` 变体（差异）**；`From<bool>` 已实现 |
| `WidgetView<M=()>` | `struct { children: Vec<WidgetView<M>>, props: PropValue, size: Option<Size>, _marker: PhantomData<M> }` | 声明式视图树节点；`empty()` / `with_size()` / 默认 `Default` |
| `Key` | `enum { Str(String), Num(u64) }` | 稳定键；`From<&str>` |
| `Callback<M>` / `MessageBinding<M>` / `MessageHandler<M>` | `view.rs` | 回调用（`MessageHandler::new()` 占位构造） |
| `HitRegion { rect, id }` / `hit_test()` | `hit_test.rs` | 命中区域 + `hit_test(x, y, &[HitRegion]) -> Option<u32>`（纯几何 `iter().find()`，D11 事件路由） |

## 9. 当前实现状态（D12 现状）

1. **已实现（D12）**：核心组件（`Accordion`/`WaBadge`）、cosmic-text 真实字形（`text.rs` draw_glyphs）、winit 事件循环 + 按需重绘（`platform/event_loop.rs`）、`App::run` 统一入口（`rgui/src/app.rs`）、窗口 surface 渲染（`vello.rs` render_surface/render_offscreen）；**hit-test 坐标命中路由**（`core::hit_test`：`HitRegion` + `hit_test(x,y,&[HitRegion])->Option<u32>`）与 `WidgetView::map_message`（递归提升子节点消息类型）；**FocusManager 焦点管理**（platform：`focus_next`/`focus_prev`/循环回绕，组件 `focusable()` 声明可获焦）。
2. **Feature 门控**：`rgui-render` 的 GPU 依赖（vello/wgpu/cosmic-text/fontdb/skrifa/pollster）经 `vello-backend`；`rgui-platform` 的 winit 经 `winit`；`rgui` 经 `window` 传递启用。默认 `default=[]`（core 例外为 `["layout"]`；platform 例外为 `["winit"]`）。
3. **编译验证**：`cargo check -p rgui-core` 通过（2 个 dead_code warning）；`cargo check --workspace` 默认通过（platform `default=["winit"]`）；`cargo check --workspace --features window` 通过（含 vello-backend+winit）。
4. **测试**：`rgui-core` 有单元测试 + `tests/layout_engine.rs`、`tests/d10_components.rs`（Accordion expand/collapse 等）通过；`rgui-macros` **无集成测试**（宏仍为透传契约，无 `tests/` 目录）。
5. **组件**：`Accordion`（`AccordionState`/`AccordionMsg`）、`WaBadge`（`WaBadgeState`/`WaBadgeMsg`）已提供。
