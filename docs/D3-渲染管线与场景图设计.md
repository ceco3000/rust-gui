---

## 1. 定位

渲染层 `rgui-render` 是唯一可能依赖 GPU / cosmic-text / fontdb 的 crate。`rgui-core` 通过「只存语义数据（Color/Size/PropValue）」与 render 彻底隔离。路径：**视图树 `WidgetView` → 布局（`LayoutEngine`）→ 场景图 `SceneGraph`（绘制指令）→ 单一 vello 渲染**。

---

## 2. 场景图与绘制指令（`scene_graph.rs`）

```rust
pub enum DrawCmd {
    FillRect { x: f32, y: f32, width: f32, height: f32, color: Color },
    DrawText { x: f32, y: f32, text: String, size: f32, color: Color, width: f32 },  // D17 width>0 换行；D23 size=语义正文(Body 13 默认)/color=语义前景(#E8E8E8 默认)
    StrokeRect { x: f32, y: f32, width: f32, height: f32, color: Color, stroke_width: f32 },  // D16 描边矩形
}
pub struct SceneGraph { cmds: Vec<DrawCmd> }
```

`SceneGraph` 方法：`new()` / `from_cmds()` / `from_view()` / `cmds()` / `push()` / `red_filled_rect(w, h)`（离屏演示用）。**不暴露 wgpu/vello 类型到公共 API**；真正的 GPU 绘制在 `vello` 模块消费此指令列表完成。

## 3. 视图树 → 场景图（`SceneGraph::from_view`）

`pub fn from_view<M>(view: &WidgetView<M>) -> Self`

- **容器尺寸**：优先取根节点 `view.size` 建议，否则用 `DEFAULT_CONTAINER`（200×200，保证有可布局空间）。
- **递归遍历**视图树。
- **子节点真实 bounds**：用 `LayoutEngine::compute_children` 计算（布局真正作用于渲染）；父节点位置累加到子节点相对位置。
- **props → 绘制指令映射**：
  - `PropValue::Color(c)` → `FillRect`（用布局尺寸/位置）。
  - `PropValue::Str(s)` → `DrawText`（**D23 语义字号** `size = view.font_size.unwrap_or(13.0)`（Body 13pt，非原误用 view.size.height）+ **语义前景色** `color = view.foreground.unwrap_or(Color::rgb(232,232,232))`（#E8E8E8 浅前景，非硬编码纯白）；**`width=size.width` 供换行，D17**）。
  - `Unit/Bool/Int/Float/WidgetId` → 无图元（或尺寸提示）。
- **border → `StrokeRect`（D16）**：`view.border = Some(Border{color, width, pad})` 时，在组件区域**外扩 pad（D16 P2 参数化，默认 2.0，非硬编码）** 绘制描边矩形（`x-pad, y-pad, w+2*pad, h+2*pad`，`stroke_width=b.width`）——获焦高亮外框，边缘不被内容覆盖。

## 4. 布局引擎（`rgui-core/src/layout/`）

`LayoutEngine` 封装 Taffy（纯 Rust，无平台/GPU），`mapping` 子模块做 `LayoutStyle → Taffy Style` 映射，**不把 Taffy 类型泄漏到公共 API**。

| 类型/方法 | 说明 |
|-----------|------|
| `LayoutEngine` | `new()`；`compute(container, children) -> LayoutResult`；`compute_children(container, children) -> Vec<LayoutResult>`（均 `#[cfg(feature="layout")]`，Taffy 门控） |
| `LayoutResult { size, position, rect }` | 布局结果（纯逻辑） |
| `LayoutNode(pub u64)` | 布局节点封装（不暴露 Taffy 类型） |
| `LayoutStyle` | 布局样式（`mapping.rs`，`to_taffy_style` 映射） |

- **当前实现状态**：`compute`/`compute_children` 为 D4 最小实现（子节点固定尺寸、flex 排布）；`LayoutResult::new(size, position)` 重建 `rect`。
- 布局计算在 `#[cfg(feature="layout")]` 下由 mapping/taffy 提供；非 layout feature 时为空实现（core 可离线编译）。

## 5. 单一 vello 渲染（`vello.rs`）

`vello-backend` feature 门控（wgpu/vello/cosmic-text/fontdb/skrifa/pollster）。

| 类型/方法 | 说明 |
|-----------|------|
| `RenderBackend` | 单一变体 `Vello(VelloBackend)`（无 skia/多后端） |
| `VelloBackend::new()` | 创建 wgpu 无窗口设备 + vello renderer（离屏） |
| `render_to_view(graph, view, w, h, scale)` | 把 `SceneGraph` 渲染到纹理视图（*`scale`* 逻辑→物理缩放，D17；离屏 1.0，surface 传窗口 scale_factor） |
| `render_offscreen(graph, w, h) -> Vec<u8>` | 离屏渲染到 RGBA8 CPU buffer（无窗口） |
| `render_surface(surface, graph, w, h, scale)` | 渲染到窗口 surface 并呈现（`scale` 逻辑→物理，D17） |
| `create_surface(window)` / `device()` / `adapter()` / `queue()` | 供 facade 配置 surface |
| `GpuSurface` | `wgpu::Surface` 别名（D8，facade 引用避免 `wgpu::` 前缀） |

**绘制编码**：`DrawCmd::FillRect` → vello `Scene::fill(rect)`；`DrawCmd::DrawText` → 真实字形（cosmic-text 整形，`scene.draw_glyphs`），无字形时矩形兜底。**D23 基底色**：`render_to_view` 的 `base_color` = 深色窗口底 **#282828**（sRGB 0.157 → `srgb_to_linear(0.157)` 传 vello，防双 gamma 提亮为 #6E6E6E）。
