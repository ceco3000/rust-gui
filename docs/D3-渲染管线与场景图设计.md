## 1. 设计目标与范围

### 1.1 本文档解决什么问题

1. 定义 Scene Graph 的完整数据结构和构建流程（Widget paint → DrawCommand → SceneGraph）
2. 定义帧循环的固定执行顺序和每阶段的时间预算
3. 定义 `RenderBackend` trait 的完整接口，支持 Vello 和 Skia 双后端
4. 定义字形 Atlas 的管理策略（分配、淘汰、GPU 上传）
5. 定义 DirtyRegion 追踪机制，实现增量渲染（仅重绘变化区域）

### 1.2 不在本文档范围内

- 样式属性的具体渲染映射（如 `background-color` → `FillRect`）（见 D4）
- 平台窗口创建和管理（见 D5，`rgui-platform`）
- 无障碍树的可视化渲染（见 D6）

### 1.3 设计原则

1. **场景图是中间表示**：Widget paint() → DrawCommand → SceneGraph → RenderBackend，每层独立
2. **增量构建**：仅 dirty widget 重新 paint()，未变化的 widget 复用上一帧的绘制指令
3. **后端可切换**：RenderBackend trait 封装所有 GPU/渲染 API 细节
4. **字形 Atlas 全局共享**：所有 widget 的字形光栅化到一个 GPU 纹理

## 2. 渲染管线架构总览

```
每帧渲染管线（按顺序执行）：

┌─────────────────────────────────────────────────────────────┐
│  1. 事件分发（rgui-platform → WidgetSpec::update）            │
│     可能修改持久状态 → 标记 dirty                             │
├─────────────────────────────────────────────────────────────┤
│  2. 布局计算（rgui-layout）                                   │
│     遍历 dirty widget 子树，Taffy compute_layout               │
│     结果写入 RenderLayoutCache                                │
├─────────────────────────────────────────────────────────────┤
│  3. 无障碍同步（rgui-a11y）                                    │
│     遍历 widget 树 → 生成 AccessibilityNode → 推送 AccessKit  │
├─────────────────────────────────────────────────────────────┤
│  4. Scene Graph 生成（rgui-render）                            │
│     仅 dirty widget 执行 paint() → DrawCommand                │
│     非 dirty widget 复用上一帧的 SceneLayer                    │
│     组装完整 SceneGraph                                       │
├─────────────────────────────────────────────────────────────┤
│  5. GPU 提交（rgui-render → Vello/Skia → wgpu）               │
│     RenderBackend::render(scene, surface, params)             │
│     Vello: Scene → Encoding → wgpu submit                     │
│     Skia (预留): Canvas API → wgpu surface                   │
└─────────────────────────────────────────────────────────────┘
```

## 3. Scene Graph 完整结构

### 3.1 核心类型

```rust
/// 场景图：Widget 树 → 绘制指令的中间表示。
///
/// SceneGraph 是渲染后端（Vello/Skia）的输入。它独立于具体渲染 API，
/// 所有 GPU 细节封装在 RenderBackend trait 的实现中。
///
/// # 增量构建
///
/// 每帧仅 dirty widget 重新生成绘制指令。非 dirty widget 的 SceneLayer
/// 从上一帧复用。dirty_layers 字段指示哪些层需要重新编码。
pub struct SceneGraph {
    /// 绘制层（按 z-order 排列，索引越小越靠下）
    pub layers: Vec<SceneLayer>,

    /// 本帧发生变化的层索引（供渲染后端做增量提交优化）
    pub dirty_layers: Vec<usize>,

    /// 裁剪区域（用于虚拟滚动、溢出裁剪等场景）
    pub clip_regions: Vec<ClipRegion>,

    /// 纹理引用（字形 Atlas、图片等）
    pub texture_refs: Vec<TextureRef>,

    /// 场景图版本号（单调递增，用于调试和缓存失效）
    pub version: u64,
}

/// 单个绘制层。
#[derive(Clone, Debug)]
pub struct SceneLayer {
    /// z 轴顺序（值越大越靠前）
    pub z_index: i32,

    /// 层的包围矩形（窗口坐标），用于快速判断可见性
    pub bounds: Rect,

    /// 绘制指令列表
    pub commands: Vec<DrawCommand>,

    /// 此层关联的 widget ID（用于调试和 dirty 追踪）
    pub widget_id: WidgetId,

    /// 层的透明度（0.0-1.0，用于动画和过渡）
    pub opacity: f32,

    /// 变换矩阵（用于 offset、scale、rotation 等）
    pub transform: Option<Transform>,
}

/// 绘制指令枚举。
///
/// 设计约束（D0 不变式 4）：使用具体枚举而非 `Box<dyn DrawCommand>`，
/// 避免渲染热点路径的动态分发开销。
#[derive(Clone, Debug)]
pub enum DrawCommand {
    /// 填充矩形
    FillRect { rect: Rect, color: Color, radius: f32 },

    /// 填充路径（贝塞尔曲线、SVG 路径等）
    FillPath { path: PathData, paint: Paint },

    /// 描边路径
    StrokePath { path: PathData, stroke: Stroke, paint: Paint },

    /// 绘制字形（批量）
    DrawGlyphs { glyphs: Vec<GlyphData>, font_size: f32, color: Color },

    /// 绘制图片/纹理
    DrawImage { texture_id: TextureId, src: Rect, dst: Rect, blend_mode: BlendMode },

    /// 推送裁剪区域（后续绘制指令在此区域内）
    PushClip { rect: Rect },

    /// 弹出裁剪区域
    PopClip,

    /// 推送变换
    PushTransform { transform: Transform },

    /// 弹出变换
    PopTransform,

    /// 推送透明度
    PushOpacity { opacity: f32 },

    /// 弹出透明度
    PopOpacity,
}
```

### 3.3 SceneGraph 构建流程

```rust
/// Scene Graph 构建器。
pub struct SceneGraphBuilder {
    layers: Vec<SceneLayer>,
    dirty_layers: Vec<usize>,
    clip_regions: Vec<ClipRegion>,
    texture_refs: Vec<TextureRef>,
    version: u64,
    prev_scene: Option<SceneGraph>,
}

impl SceneGraphBuilder {
    pub fn new(version: u64) -> Self {
        SceneGraphBuilder {
            layers: Vec::new(), dirty_layers: Vec::new(),
            clip_regions: Vec::new(), texture_refs: Vec::new(),
            version, prev_scene: None,
        }
    }

    pub fn with_prev(mut self, prev: SceneGraph) -> Self {
        self.prev_scene = Some(prev);
        self
    }

    /// 构建 dirty widget 的绘制指令。
    pub fn build_layer(
        &mut self, widget_id: WidgetId, z_index: i32,
        bounds: Rect, commands: Vec<DrawCommand>, is_dirty: bool,
    ) {
        let layer_index = self.layers.len();
        self.layers.push(SceneLayer {
            z_index, bounds, commands, widget_id,
            opacity: 1.0, transform: None,
        });
        if is_dirty { self.dirty_layers.push(layer_index); }
    }

    /// 完成构建，产出 SceneGraph。
    pub fn finish(mut self) -> SceneGraph {
        self.layers.sort_by_key(|l| l.z_index);
        SceneGraph {
            layers: self.layers,
            dirty_layers: self.dirty_layers,
            clip_regions: self.clip_regions,
            texture_refs: self.texture_refs,
            version: self.version,
        }
    }
}
```

## 4. 帧循环详细设计

### 4.1 帧循环主函数

```rust
/// 框架主循环（每帧调用）。
///
/// # 固定执行顺序（经 V1/V6 验证）
///
/// 1. 事件分发（事件可能改变状态）
/// 2. 布局计算（需要最新的状态和样式）
/// 3. 无障碍同步（需要布局结果获取位置）
/// 4. 场景图生成（仅 dirty widget）
/// 5. GPU 提交
///
/// # 帧预算
///
/// 每帧总预算 ≤ 17ms（目标 120fps）。
pub fn tick(
    &mut self,
    events: Vec<WindowEvent>,
    backend: &mut dyn RenderBackend,
    surface: &RenderSurface,
) {
    let frame_start = Instant::now();

    // 阶段 1：事件分发（≤ 3ms）
    self.dispatch_events(events);

    // 阶段 2：布局计算（≤ 3ms）
    self.layout_dirty();

    // 阶段 3：无障碍同步（≤ 1ms）
    self.update_accessibility();

    // 阶段 4：场景图生成（≤ 5ms）
    let scene = self.generate_scene();

    // 阶段 5：GPU 提交（≤ 5ms）
    let params = RenderParams {
        width: surface.width(),
        height: surface.height(),
        scale_factor: surface.scale_factor(),
        background_color: self.theme.background_color(),
    };
    if let Err(e) = backend.render(&scene, surface, &params) {
        log::error!("渲染失败：{:?}", e);
    }

    let elapsed_us = frame_start.elapsed().as_micros();
    if elapsed_us > 17_000 {
        log::warn!("帧超时：{}µs（目标 ≤ 17000µs）", elapsed_us);
    }
}
```

### 4.2 各阶段实现要点

**阶段 1：事件分发**（见 D5 事件系统）— 平台事件转换为 `WidgetSpec::update()` 调用。命中测试确定目标 widget。焦点 widget 接收键盘事件。

**阶段 2：布局计算**（见 D2 状态管理）— 遍历 dirty widget 子树，调用 `measure()` 获取期望尺寸，提交到 Taffy 布局引擎。Taffy `compute_layout()` 后结果缓存到 `RenderLayoutCache`。

**阶段 3：无障碍同步**（见 D6 无障碍系统）— 遍历可见 widget 树，调用 `accessibility()` 生成 `AccessibilityNode`，组装为 `TreeUpdate` 推送 AccessKit。

**阶段 4：场景图生成** — 仅 dirty widget 执行 `paint()` 生成 `DrawCommand` 列表。非 dirty widget 的 SceneLayer 从上一帧复用。产出 SceneGraph 后 version 递增。

**阶段 5：GPU 提交** — `RenderBackend::render()` 将 DrawCommand 转换为 Vulkan/Metal/DX12 指令。Vello 后端通过 wgpu 提交。增量提交优化：仅重编码 dirty_layers。

## 5. RenderBackend trait 与可插拔设计

### 5.1 trait 完整定义

```rust
/// 渲染后端抽象。
///
/// 封装所有 GPU/渲染 API 细节。框架通过此 trait 调用渲染，
/// 不感知底层使用 Vello、Skia 还是其他引擎。
pub trait RenderBackend: Send + Sync {
    /// 提交场景图并渲染到表面。
    fn render(
        &mut self,
        scene: &SceneGraph,
        surface: &RenderSurface,
        params: &RenderParams,
    ) -> Result<(), RenderError>;

    /// 注册纹理数据。
    fn register_texture(&mut self, data: &TextureData, format: TextureFormat) -> TextureId;

    /// 释放纹理。
    fn unregister_texture(&mut self, id: TextureId);

    /// 更新纹理内容（用于字形 Atlas 动态增长）。
    fn update_texture(
        &mut self, id: TextureId,
        x: u32, y: u32, width: u32, height: u32, data: &[u8],
    );

    /// 后端名称。
    fn backend_name(&self) -> &'static str;

    /// 后端是否可用。
    fn is_available(&self) -> bool;

    /// 后端特性集。
    fn capabilities(&self) -> BackendCapabilities;
}

#[derive(Debug, Clone)]
pub struct BackendCapabilities {
    pub msaa: bool,
    pub max_texture_size: u32,
    pub gpu_tessellation: bool,
    pub hdr: bool,
    pub offscreen_rendering: bool,
}

#[derive(Debug, Clone)]
pub struct RenderParams {
    pub width: u32,
    pub height: u32,
    pub scale_factor: f64,
    pub background_color: Color,
}

#[derive(Debug, thiserror::Error)]
pub enum RenderError {
    #[error("GPU 设备不可用")]
    DeviceLost(#[source] wgpu::RequestDeviceError),
    #[error("表面创建失败：{0}")]
    SurfaceCreationFailed(String),
    #[error("着色器编译失败：{0}")]
    ShaderCompilationFailed(String),
    #[error("纹理内存不足")]
    OutOfTextureMemory,
    #[error("渲染超时（>{0}ms）")]
    Timeout(u64),
    #[error("后端不可用：{0}")]
    BackendUnavailable(String),
}
```

### 5.2 后端选择策略

```rust
pub struct RenderBackendFactory;

impl RenderBackendFactory {
    /// 自动选择最佳可用后端。优先级：Vello > Skia > 错误。
    pub fn create() -> Result<Box<dyn RenderBackend>, RenderError> {
        match VelloBackend::new() {
            Ok(backend) => {
                log::info!("使用 Vello 渲染后端");
                return Ok(Box::new(backend));
            }
            Err(e) => log::warn!("Vello 后端初始化失败：{:?}，尝试 Skia fallback", e),
        }
        match SkiaBackend::new() {
            Ok(backend) => {
                log::info!("使用 Skia 渲染后端（fallback）");
                return Ok(Box::new(backend));
            }
            Err(e) => {
                log::error!("所有渲染后端初始化失败");
                Err(e)
            }
        }
    }
}
```

### 6.3 实现骨架

```rust
pub struct VelloBackend {
    device: wgpu::Device,
    queue: wgpu::Queue,
    renderer: vello::Renderer,
    textures: FxHashMap<TextureId, wgpu::Texture>,
    next_texture_id: u64,
    capabilities: BackendCapabilities,
}

impl VelloBackend {
    pub fn new() -> Result<Self, RenderError> {
        let instance = wgpu::Instance::new(wgpu::InstanceDescriptor::default());
        let adapter = pollster::block_on(instance.request_adapter(
            &wgpu::RequestAdapterOptions {
                power_preference: wgpu::PowerPreference::HighPerformance,
                compatible_surface: None,
                force_fallback_adapter: false,
            },
        )).ok_or_else(|| RenderError::BackendUnavailable("无法获取 GPU 适配器".into()))?;

        let (device, queue) = pollster::block_on(adapter.request_device(
            &wgpu::DeviceDescriptor {
                label: Some("rgui Vello 后端"),
                required_features: wgpu::Features::default(),
                required_limits: wgpu::Limits::default(),
                memory_hints: wgpu::MemoryHints::Performance,
            },
            None,
        )).map_err(RenderError::DeviceLost)?;

        let renderer = vello::Renderer::new(
            &device,
            vello::RendererOptions {
                surface_format: None,
                use_cpu: false,
                num_init_threads: 4,
            },
        ).map_err(|e| RenderError::BackendUnavailable(e.to_string()))?;

        Ok(VelloBackend {
            device, queue, renderer,
            textures: FxHashMap::default(),
            next_texture_id: 1,
            capabilities: BackendCapabilities {
                msaa: true, max_texture_size: 8192,
                gpu_tessellation: true, hdr: false, offscreen_rendering: true,
            },
        })
    }
}

impl RenderBackend for VelloBackend {
    fn render(
        &mut self, scene: &SceneGraph,
        surface: &RenderSurface, params: &RenderParams,
    ) -> Result<(), RenderError> {
        let mut vello_scene = vello::Scene::new();

        for layer in &scene.layers {
            for cmd in &layer.commands {
                match cmd {
                    DrawCommand::FillRect { rect, color, radius } => {
                        vello_scene.fill(
                            vello::peniko::Fill::NonZero,
                            vello::kurbo::Affine::IDENTITY,
                            to_vello_color(*color),
                            None,
                            &rounded_rect_path(*rect, *radius),
                        );
                    }
                    DrawCommand::FillPath { path, paint } => {
                        // 转换路径和画笔到 vello 类型
                        let vello_path = to_vello_path(path);
                        // ...
                    }
                    DrawCommand::DrawGlyphs { glyphs, font_size, color } => {
                        for glyph in glyphs {
                            // 逐个字形绘制
                        }
                    }
                    _ => {}
                }
            }
        }

        let surface_texture = surface.acquire(&self.device)?;
        self.renderer.render_to_surface(
            &self.device, &self.queue, &vello_scene, &surface_texture,
            &vello::RenderParams {
                base_color: to_vello_color(params.background_color),
                width: params.width, height: params.height,
                antialiasing_method: vello::AaConfig::Area,
            },
        ).map_err(|e| RenderError::SurfaceCreationFailed(e.to_string()))?;

        surface_texture.present();
        self.device.poll(wgpu::Maintain::Poll);
        Ok(())
    }

    fn register_texture(&mut self, data: &TextureData, format: TextureFormat) -> TextureId {
        let id = TextureId(self.next_texture_id);
        self.next_texture_id += 1;
        let texture = self.device.create_texture(&wgpu::TextureDescriptor {
            label: Some("rgui texture"),
            size: wgpu::Extent3d { width: data.width, height: data.height, depth_or_array_layers: 1 },
            mip_level_count: 1, sample_count: 1,
            dimension: wgpu::TextureDimension::D2,
            format: to_wgpu_format(format),
            usage: wgpu::TextureUsages::TEXTURE_BINDING | wgpu::TextureUsages::COPY_DST,
            view_formats: &[],
        });
        self.queue.write_texture(
            wgpu::ImageCopyTexture { texture: &texture, mip_level: 0, origin: wgpu::Origin3d::ZERO, aspect: wgpu::TextureAspect::All },
            &data.pixels,
            wgpu::ImageDataLayout { offset: 0, bytes_per_row: Some(4 * data.width), rows_per_image: Some(data.height) },
            wgpu::Extent3d { width: data.width, height: data.height, depth_or_array_layers: 1 },
        );
        self.textures.insert(id, texture);
        id
    }

    fn unregister_texture(&mut self, id: TextureId) { self.textures.remove(&id); }
    fn update_texture(&mut self, id: TextureId, x: u32, y: u32, width: u32, height: u32, data: &[u8]) {
        if let Some(texture) = self.textures.get(&id) {
            self.queue.write_texture(
                wgpu::ImageCopyTexture { texture, mip_level: 0, origin: wgpu::Origin3d { x, y, z: 0 }, aspect: wgpu::TextureAspect::All },
                data,
                wgpu::ImageDataLayout { offset: 0, bytes_per_row: Some(4 * width), rows_per_image: Some(height) },
                wgpu::Extent3d { width, height, depth_or_array_layers: 1 },
            );
        }
    }
    fn backend_name(&self) -> &'static str { "Vello" }
    fn is_available(&self) -> bool { true }
    fn capabilities(&self) -> BackendCapabilities { self.capabilities.clone() }
}
```

### 8.2 核心操作

```rust
impl GlyphAtlas {
    pub fn new(texture_id: TextureId, initial_w: u32, initial_h: u32) -> Self {
        GlyphAtlas {
            texture_id, width: initial_w, height: initial_h,
            max_width: 4096, max_height: 4096,
            glyphs: FxHashMap::default(),
            skyline: SkylineAllocator::new(initial_w, initial_h),
            lru_counter: FxHashMap::default(),
            frame_index: 0, dirty: false, upload_queue: Vec::new(),
        }
    }

    /// 请求字形缓存。若不存在则触发光栅化并分配 Atlas 空间。
    pub fn get_or_rasterize(
        &mut self,
        key: GlyphKey,
        rasterizer: &dyn Fn(&GlyphKey) -> RasterizedGlyph,
    ) -> Option<GlyphCacheEntry> {
        // 缓存命中
        if let Some(entry) = self.glyphs.get(&key) {
            self.lru_counter.insert(key.clone(), self.frame_index);
            return Some(entry.clone());
        }

        let rasterized = rasterizer(&key);

        // 分配 Atlas 空间（尝试分配 → 增长 → 淘汰）
        let alloc = self.skyline.allocate(rasterized.width, rasterized.height)
            .or_else(|| {
                self.grow(rasterized.width, rasterized.height);
                self.skyline.allocate(rasterized.width, rasterized.height)
            })
            .or_else(|| {
                self.evict_lru();
                self.skyline.allocate(rasterized.width, rasterized.height)
            })?;

        self.upload_queue.push(UploadRect {
            x: alloc.x, y: alloc.y,
            width: rasterized.width, height: rasterized.height,
            data: rasterized.bitmap,
        });
        self.dirty = true;

        let entry = GlyphCacheEntry {
            atlas_u: alloc.x as f32 / self.width as f32,
            atlas_v: alloc.y as f32 / self.height as f32,
            width: rasterized.width as f32,
            height: rasterized.height as f32,
            advance: rasterized.advance,
        };

        self.glyphs.insert(key.clone(), entry.clone());
        self.lru_counter.insert(key, self.frame_index);
        Some(entry)
    }

    fn grow(&mut self, needed_w: u32, needed_h: u32) {
        if self.width < self.max_width {
            self.width = (self.width * 2).min(self.max_width);
            self.skyline.resize(self.width, self.height);
        } else if self.height < self.max_height {
            self.height = (self.height * 2).min(self.max_height);
            self.skyline.resize(self.width, self.height);
        }
    }

    fn evict_lru(&mut self) {
        let mut entries: Vec<_> = self.lru_counter.iter().collect();
        entries.sort_by_key(|(_, &frame)| frame);
        let evict_count = entries.len() / 4;
        for (key, _) in entries.iter().take(evict_count) {
            if let Some(entry) = self.glyphs.remove(*key) {
                self.skyline.free(
                    (entry.atlas_u * self.width as f32) as u32,
                    (entry.atlas_v * self.height as f32) as u32,
                    entry.width as u32, entry.height as u32,
                );
            }
            self.lru_counter.remove(*key);
        }
    }

    pub fn advance_frame(&mut self) { self.frame_index += 1; }
    pub fn take_uploads(&mut self) -> Vec<UploadRect> {
        self.dirty = false;
        std::mem::take(&mut self.upload_queue)
    }
}

pub struct RasterizedGlyph {
    pub width: u32, pub height: u32,
    pub bitmap: Vec<u8>,  // 单通道 alpha
    pub advance: f32,
}
```

## 9. DirtyRegion 追踪与增量渲染

```rust
/// 脏区域追踪器。
///
/// 记录本帧需要重绘的屏幕区域。渲染后端可据此做增量提交。
pub struct DirtyRegionTracker {
    regions: Vec<Rect>,
}

impl DirtyRegionTracker {
    pub fn new() -> Self { DirtyRegionTracker { regions: Vec::new() } }

    pub fn add_dirty(&mut self, rect: Rect) { self.regions.push(rect); }

    /// 合并重叠和相邻的脏矩形。
    pub fn coalesce(&mut self) {
        if self.regions.len() <= 1 { return; }
        let mut merged = Vec::new();
        let mut sorted = self.regions.clone();
        sorted.sort_by(|a, b| a.x.partial_cmp(&b.x).unwrap());

        let mut current = sorted[0];
        for rect in sorted.iter().skip(1) {
            if rects_near(&current, rect, 2.0) {
                current = merge_rects(current, *rect);
            } else {
                merged.push(current);
                current = *rect;
            }
        }
        merged.push(current);
        self.regions = merged;
    }

    pub fn regions(&self) -> &[Rect] { &self.regions }
    pub fn has_dirty(&self) -> bool { !self.regions.is_empty() }
    pub fn clear(&mut self) { self.regions.clear(); }
}

fn rects_near(a: &Rect, b: &Rect, margin: f32) -> bool {
    let (ax2, ay2) = (a.x + a.width, a.y + a.height);
    let (bx2, by2) = (b.x + b.width, b.y + b.height);
    !(ax2 + margin < b.x || bx2 + margin < a.x || ay2 + margin < b.y || by2 + margin < a.y)
}

fn merge_rects(a: Rect, b: Rect) -> Rect {
    let x = a.x.min(b.x);
    let y = a.y.min(b.y);
    let x2 = (a.x + a.width).max(b.x + b.width);
    let y2 = (a.y + a.height).max(b.y + b.height);
    Rect { x, y, width: x2 - x, height: y2 - y }
}
```

## 10. 与布局引擎（rgui-layout）的交互

### 10.1 职责边界

| 职责 | 归属 |
|------|------|
| 组件期望尺寸计算 | `WidgetSpec::measure()` → rgui-render 调用 |
| CSS → Taffy Style 转换 | rgui-layout |
| Taffy 布局计算 | rgui-layout |
| 布局结果缓存 | rgui-render（`RenderLayoutCache`） |
| 布局结果 → 屏幕坐标 | rgui-render（scene 构建时使用） |

### 10.2 触发重布局的条件

1. 窗口大小变更
2. 组件期望尺寸变更（measure() 返回不同 Size）
3. 父容器尺寸变更
4. 样式 display/flex/grid 属性变更
5. DPI 变更

### 10.3 WidgetView → 布局 → Paint → SceneGraph 声明式渲染管线

> **状态：** 设计完成，实现中。

#### 10.3.1 管线概述

`html!` 宏 / `.html` 文件解析 → `WidgetView<M>` 树 → **Taffy 布局计算** → **per-widget 状态提取** → `paint()` → `DrawCommand` → `SceneGraph`。

这是 rgui 声明式 UI 的完整渲染链路，对标 Web 浏览器的 HTML → CSS 布局 → 绘制的核心流程。

```
html! { <Column> <Label text="Hi" /> <Button label="OK" /> </Column> }
  │
  ▼
WidgetView 树 (rgui-core)
  │  widget_type="Column", props={}
  ├── widget_type="Label",  props={text: "Hi"}
  └── widget_type="Button", props={label: "OK"}
  │
  ▼ 阶段 1: 布局计算 (rgui-layout)
  │   view() → CSS props → Taffy Style
  │   WidgetView 树 → Taffy 节点树
  │   taffy.compute_layout() → 每个 widget 的 (x, y, w, h)
  │
  ▼ 阶段 2: 状态提取 (rgui-render / scene_build)
  │   WidgetView.props → WidgetState
  │   "Label" + props={text: "Hi"} → LabelState { text: "Hi" }
  │   "Button" + props={label: "OK"} → ButtonState { label: "OK" }
  │
  ▼ 阶段 3: Paint 分发
  │   per-widget: paint_fn(widget_type, state, computed_bounds) → Vec<PaintOp>
  │
  ▼
SceneGraph → RenderBackend (Vello/Skia) → GPU
```

#### 10.3.2 阶段 1：布局计算（rgui-layout 集成）

| 步骤 | 说明 |
|------|------|
| 1. 遍历 `WidgetView` 树 | DFS 遍历，为每个 widget 创建 Taffy `Node` |
| 2. `view()` → CSS props | 调用每个 widget 的 `view()` 获取 CSS 属性（`display: flex`、`flex-direction` 等），映射为 Taffy `Style` |
| 3. 设置父子关系 | `taffy.add_child(parent, child)` 建立布局树 |
| 4. `compute_layout()` | 调用 Taffy 单次布局计算，得到所有节点的 `Layout { x, y, width, height }` |
| 5. 缓存结果 | 将布局结果存入 `LayoutCache`（HashMap<WidgetId, Rect>），供阶段 3 使用 |

**关键约束：**
- 布局计算在每帧渲染前执行一次（`tick()` 的布局阶段）
- 仅当 D3 §10.2 的五种触发条件之一满足时才重新计算（增量重布局）
- `Container`/`Row`/`Column` 等布局容器的 `measure()` 返回 `Size::ZERO`——尺寸完全由 Taffy 决定
- 叶子组件（`Button`、`Label`）的 `measure()` 返回期望尺寸——Taffy 在约束下分配实际尺寸

#### 10.3.3 阶段 2：状态提取

`default_paint_fn()` 从 `WidgetView.props` 提取属性构造真实 `WidgetState`：

| Widget | 从 props 提取 | 构造的 State |
|--------|--------------|-------------|
| `Label` | `text` | `LabelState { text: props["text"].as_str() }` |
| `Button` | `label` | `ButtonState::new(props["label"].as_str())` |
| `CheckBox` | `label`, `checked` | `CheckBoxState { label, checked }` |
| `Slider` | `value`, `min`, `max` | `SliderState::new(value, min, max)` |
| 布局容器 | — | 空 State（`paint()` 不绘制自身） |

**与旧方式的区别：**
- **旧**：`default_paint_fn` 用硬编码默认值（`text: ""`、`label: "Button"`）
- **新**：`default_paint_fn` 从 `WidgetView.props` 读取 html! 声明的实际值

#### 10.3.4 阶段 3：Paint 分发

`build_scene_from_view()` 遍历 WidgetView 树，对每个节点：

1. 从 `LayoutCache` 查询该 widget 的布局结果（阶段 1 的输出）
2. 调用 `paint_fn(widget_type, widget_id, computed_bounds)` 获取 `Vec<PaintOp>`
3. 将 `PaintOp` 转换为 `DrawCommand`，加入 `SceneGraph`

**关键改进**（vs 当前实现）：

| 当前实现 | 修复后 |
|---------|--------|
| 所有子节点继承根 `bounds`（全窗口） | 每个节点使用 Taffy 计算的精确 `bounds` |
| `paint_fn` 不接收 `props`，使用硬编码 State | `paint_fn` 接收 `&WidgetView`，从 `props` 提取实际值 |
| 无布局缓存 | `LayoutCache` 仅脏节点重计算 |

#### 10.3.5 实现任务（见 D8 §9.11）

| ID | 任务 | 优先级 |
|----|------|--------|
| V01 | 布局计算集成——WidgetView → Taffy 节点树 → compute_layout() | P0 |
| V02 | 状态提取——WidgetView.props → WidgetState | P0 |
| V03 | PaintFn 重写——合并布局结果 + 实际状态 → paint() | P0 |

## 12. 边界情况处理

### 12.1 空场景图

- `SceneGraph::layers` 为空：合法，渲染背景色

### 12.2 GPU 设备丢失

- 检测：`wgpu::Device::poll()` 返回设备丢失
- 处理：重建 `VelloBackend`（重新创建 Device/Queue），重新上传所有纹理
- 用户影响：单帧闪烁后恢复

### 12.3 字形 Atlas 溢出

- Atlas 已增长到最大尺寸（4096×4096）
- 处理：淘汰 LRU 字形（先淘汰 25% 最冷字形），如仍失败降级到系统字体

### 12.4 窗口最小化

- wgpu surface 不可用时跳过渲染阶段，不视为错误

### 12.5 后端切换

- Vello 失败 → Skia fallback
- 切换在帧边界进行：完成当前帧（跳过渲染），下一帧使用新后端
