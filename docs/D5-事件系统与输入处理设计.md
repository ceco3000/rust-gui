## 1. 定位

事件系统：winit 窗口事件 → （mapper）→ 组件消息 `M` → `Coordinator::dispatch` 更新状态 → 重绘。平台层 `rgui-platform` 是 winit 隔离处；`rgui-core` 零平台依赖（不直接引用 `winit::`）。

### `focus.rs`（D12 增强）
```rust
pub struct FocusManager { focused: Option<WidgetId>, focusable: Vec<WidgetId> }  // 焦点管理原生在此
impl FocusManager {
    pub fn new() -> Self;
    pub fn set_modality(&mut self, _modality: InputModality);  // 模态层级留后续
    pub fn set_focusable(&mut self, ids: Vec<WidgetId>);       // 注册可获焦组件（有序，供 Tab 循环）
    pub fn set_focus(&mut self, widget_id: WidgetId) -> bool;  // 设焦点（仅可获焦成功）；返回是否设置
    pub fn focus(&self) -> Option<WidgetId>;                   // 当前焦点
    pub fn is_focused(&self, widget_id: WidgetId) -> bool;     // 获焦查询
    pub fn focusable(&self) -> &[WidgetId];                    // 可获焦列表
    pub fn focus_next(&mut self) -> Option<WidgetId>;          // Tab：循环下一个可获焦
    pub fn focus_prev(&mut self) -> Option<WidgetId>;          // Shift+Tab：循环上一个可获焦
}
```

## 3. 事件 → 消息映射（facade `App::run`）

`rgui/src/app.rs`：`App::run(config, widget, state, mapper)`（`#[cfg(feature="window")]` 门控），`mapper: FnMut(&WindowEvent) -> Option<W::Message> + 'static`。

- 每收到窗口事件，调用 `mapper(event)`：返回 `Some(msg)` → `Coordinator::dispatch(msg, &mut UpdateContext)` 更新状态并置脏（请求重绘）；返回 `None` → 不重绘。
- 事件源：`AppRunnerImpl::event`（内部 `platform::AppRunner` 实现），调用 `mapper`。

**实际映射示例**（`rgui/examples/window_demo.rs`）：
```rust
let mapper = |event: &WindowEvent| -> Option<AccordionMsg> {
    match event {
        WindowEvent::MouseInput { state: Pressed, button: Left, .. } => Some(AccordionMsg::Toggle),
        WindowEvent::KeyboardInput { event, .. }
            if event.state == Pressed && event.physical_key == Code(KeyCode::Space) =>
            Some(AccordionMsg::Toggle),
        _ => None,
    }
};
```

## 4. 事件传播与 hit-test（当前实现状态）

- `EventResult<M>`（`Handled`/`Prevented`/`Continue(M)`）在 `rgui-core` 定义，用于事件传播决策；当前组件层由 mapper 直接映射到单组件消息。
- **hit-test 已实现（D11）**：`rgui-core::hit_test` 提供 `HitRegion`（区域矩形 + id）+ `hit_test(x, y, &[HitRegion]) -> Option<id>`（纯几何，`iter().find()` 流式）。demo（`window_demo.rs`）把点击坐标经 `hit_test` 命中对应组件区，路由到该组件消息（Accordion 标题区 → Toggle；WaBadge 区 → Click）。多组件同窗各自响应点击。

## 5. 当前实现状态（D12，写实）

1. **已实现**：winit 事件循环 + 按需重绘（`event_loop.rs`）；`WindowEvent` → mapper → 组件消息链路；**hit-test 坐标命中路由**（`rgui-core::hit_test` + demo 多组件各自响应）；**FocusManager 焦点管理**（可获焦列表 + Tab/Shift+Tab 循环切换 + `WidgetSpec::focusable`），Accordion 点击/Space 切换 + WaBadge 点击计数。
2. **未实现（后续）**：`InputEvent`/`ImeEvent` 真实驱动（当前为占位类型）、焦点**视觉透传**（获焦组件高亮，需视图层焦点状态，当前 demo 用日志展示 Tab 切换）、`FocusManager` 的模态层级（modal layer）、hit-test 的 scale_factor 换算（demo 当前把点击坐标视作逻辑坐标）。
3. **依赖隔离**：`rgui-core` 不引用 `winit::`；平台 winit 默认启用（`default=["winit"]`）。
