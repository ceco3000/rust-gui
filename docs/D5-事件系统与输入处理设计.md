## 3. 事件 → 消息映射（facade `App::run`）

`rgui/src/app.rs`：`App::run(config, widget, state, mapper)`（`#[cfg(feature="window")]` 门控），`mapper: FnMut(&WindowEvent) -> Option<W::Message> + 'static`。

- 每收到窗口事件，调用 `mapper(event)`：返回 `Some(msg)` → `Coordinator::dispatch(msg, &mut UpdateContext)` 更新状态并置脏（请求重绘）；返回 `None` → 不重绘。
- 事件源：`AppRunnerImpl::event`（内部 `platform::AppRunner` 实现），调用 `mapper`。

**实际映射示例**（`rgui/examples/window_demo.rs`）：
```rust
let mapper = |event: &WindowEvent| -> Option<AccordionMsg> {
    match event {
        WindowEvent::MouseInput { state: Pressed, button: Left, .. } => Some(AccordionMsg::Toggle),
        WindowEvent::KeyboardInput { event, .. }
            if event.state == Pressed && event.physical_key == Code(KeyCode::Space) =>
            Some(AccordionMsg::Toggle),
        _ => None,
    }
};
```

## 4. 事件传播与 hit-test（当前实现状态）

- `EventResult<M>`（`Handled`/`Prevented`/`Continue(M)`）在 `rgui-core` 定义，用于事件传播决策；当前组件层由 mapper 直接映射到单组件消息。
- **hit-test 已实现（D11）**：`rgui-core::hit_test` 提供 `HitRegion`（区域矩形 + id）+ `hit_test(x, y, &[HitRegion]) -> Option<id>`（纯几何，`iter().find()` 流式）。demo（`window_demo.rs`）把点击坐标经 `hit_test` 命中对应组件区，路由到该组件消息（Accordion 标题区 → Toggle；WaBadge 区 → Click）。多组件同窗各自响应点击。

## 5. 当前实现状态（D21，写实）

1. **已实现**：winit 事件循环 + 按需重绘（`event_loop.rs`）；`WindowEvent` → mapper → 组件消息链路；**hit-test 坐标命中路由**（`rgui-core::hit_test` + demo 多组件各自响应）；**FocusManager 焦点管理**（可获焦列表 + Tab/Shift+Tab 循环切换 + `WidgetSpec::focusable`）；**焦点视觉透传（D13/D14/D16）**——`ViewContext.focused` → `WidgetView.border` → SceneGraph `StrokeRect` → vello `stroke`（获焦描边高亮）；**scale_factor 坐标换算（D15/D17）**——`window::to_logical`（hit-test 物理→逻辑）+ **渲染尺寸统一（D17）**：`render_to_view/render_surface` 按 `scale` 对 SceneGraph 施加缩放（逻辑→物理），Retina/高分屏内容不再偏小；**组件样式驱动（D19）**——`ViewContext.styles`（默认主题单例），组件 view `styles.lookup(selector)` 取配色/描边（命中用样式、未命中回退默认）；**FocusManager 动态增删焦点边界（D18）**——`set_focusable` 变化时被移除焦点清空、保留焦点不变。**key-based reconcile（D18）**——`WidgetView.key` + `diff` 按 key 复用子节点（`MoveChild`），动态增删组件不误伤邻位。**文本换行（D17）**——`shape_line(max_width)`（cosmic-text 按宽度换行多行），`DrawText.width` 传递组件可用宽，长文本不溢出。**InputEvent/ImeEvent 真实驱动（D20）**——`event_loop::to_input_event`/`to_ime_event`（winit 事件 → rgui `InputEvent`/`ImeEvent`：光标/按下/释放/文本 + IME Preedit/Commit/Enabled/Disabled 真实转换链路）。**模态层级（D20）**——`FocusManager::open_modal`/`close_modal`/`is_modal_open`（模态浮层焦点隔离在模态集合内、`base_focusable`/`base_focused` 恢复，关闭恢复打开前焦点）。**调试日志（D21）**——demo（window_demo.rs）输出 `[hit-region] id=<id> <name> rect=(逻辑坐标,与 hit_test regions 一致)` 与 `[focus] Tab(shift=..) -> ..`；facade（app.rs）输出 `[win-frame] origin=(物理屏幕坐标) size=(w,h) scale=<f>`（`last_frame` 缓存避免刷屏）；供鼠标/键盘自动化脚本（tools/qa/rgui_input_test.py 之 parse_win_frame）作坐标来源；demo 左键按下另输出 `[mouse-event] left-press at logical=(x,y)`（事件到达确认，逻辑坐标与 hit-test 一致）+ `[hit] id=<id> -> <msg>`（命中路由，如 id=1->AccordionMsg::Toggle / id=2->WaBadgeMsg::Click / id=none missed）+ `[action] toggle(id) / badge_click(id,count)`（动作），供自动化测试坐标/命中断言。**测试辅助 eprintln，不改变事件链路**。
