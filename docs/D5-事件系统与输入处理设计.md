## 1. 设计目标与范围

### 1.1 本文档解决什么问题

1. 定义从 winit 原始事件到框架事件的类型体系
2. 定义事件在 widget 树中的路由机制（捕获 + 目标 + 冒泡三阶段）
3. 定义命中测试算法（确定哪个 widget 响应坐标点击）
4. 定义焦点管理（Tab 导航、焦点链、焦点恢复）
5. 定义 IME 集成接口（组合文本、候选窗口位置）

### 1.2 设计原则

1. **事件是不可变值类型**：事件在传递链中为只读
2. **命中测试基于布局结果**：使用 Taffy 产出的 widget 边界矩形
3. **焦点遵循 WCAG**：Tab 序遵循视觉顺序，支持焦点陷阱（模态对话框）

### 2.1 框架事件枚举

```rust
/// 框架统一事件类型（从 winit 原始事件转换）。
#[derive(Debug, Clone)]
pub enum Event {
    // 鼠标事件
    MouseDown { position: Point, button: MouseButton, modifiers: Modifiers },
    MouseUp { position: Point, button: MouseButton, modifiers: Modifiers },
    MouseMove { position: Point, delta: Point, modifiers: Modifiers },
    MouseWheel { position: Point, delta: ScrollDelta, modifiers: Modifiers },
    MouseEnter { widget_id: WidgetId },
    MouseLeave { widget_id: WidgetId },

    // 键盘事件
    KeyDown { key: Key, modifiers: Modifiers, repeat: bool },
    KeyUp { key: Key, modifiers: Modifiers },

    // IME 事件
    ImePreedit { text: String, cursor_offset: usize },
    ImeCommit { text: String },
    ImeEnabled, ImeDisabled,

    // 焦点事件
    FocusIn { widget_id: WidgetId, source: FocusSource },
    FocusOut { widget_id: WidgetId },

    // 拖放
    DragEnter { position: Point, data: DragData },
    DragOver { position: Point },
    DragLeave,
    Drop { position: Point, data: DragData },

    // 系统事件
    WindowResized { width: f64, height: f64 },
    WindowFocused, WindowUnfocused,
    ScaleFactorChanged { scale_factor: f64 },
    ThemeChanged { color_scheme: ColorScheme },
    CloseRequested,
}

#[derive(Debug, Clone, Copy)]
pub struct Modifiers {
    pub shift: bool, pub ctrl: bool, pub alt: bool, pub meta: bool,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum FocusSource { Keyboard, Mouse, Programmatic }
```

### 2.3 事件流

```
winit WindowEvent
  → rgui-platform::convert_event() → Event
  → 命中测试（确定 target WidgetId）
  → 捕获阶段（根→target 路径上传递）
  → 目标阶段（调用 WidgetSpec::update()）
  → 冒泡阶段（target→根 路径上传递）
```

## 3. 事件路由（冒泡/捕获）

### 3.1 路由架构

```rust
pub struct EventRouter {
    tree: WidgetTree,
    focus: FocusManager,
}

pub struct WidgetTree {
    parent: FxHashMap<WidgetId, WidgetId>,
    children: FxHashMap<WidgetId, Vec<WidgetId>>,
    bounds: FxHashMap<WidgetId, Rect>,
}

impl EventRouter {
    /// 分发事件到 widget 树。
    pub fn dispatch(
        &self, event: &Event,
        state_store: &mut StateStore, registry: &WidgetRegistry,
    ) {
        match event {
            Event::MouseDown { position, .. }
            | Event::MouseUp { position, .. }
            | Event::MouseMove { position, .. } => {
                if let Some(target) = self.hit_test(*position) {
                    self.dispatch_to_path(event, target, state_store, registry);
                }
            }
            Event::KeyDown { .. } | Event::KeyUp { .. } => {
                if let Some(id) = self.focus.current() {
                    self.dispatch_direct(event, id, state_store, registry);
                }
            }
            _ => {}
        }
    }

    /// 沿树路径分发：捕获 → 目标 → 冒泡。
    fn dispatch_to_path(
        &self, event: &Event, target: WidgetId,
        state_store: &mut StateStore, registry: &WidgetRegistry,
    ) {
        let path = self.tree.path_to_root(target);

        // 捕获阶段（从根向下，不包括 target）
        for &ancestor in path.iter().rev().skip(1) {
            if self.send_event(event, ancestor, EventPhase::Capture, state_store, registry) {
                return;
            }
        }

        // 目标阶段
        if self.send_event(event, target, EventPhase::Target, state_store, registry) {
            return;
        }

        // 冒泡阶段（从 target 向上，不包括根）
        for &ancestor in path.iter().skip(1) {
            if self.send_event(event, ancestor, EventPhase::Bubble, state_store, registry) {
                return;
            }
        }
    }
}
```

## 4. 命中测试

```rust
impl WidgetTree {
    /// 命中测试：返回坐标处最深的 widget ID。
    ///
    /// 算法：
    /// 1. 从根节点开始
    /// 2. 检查当前节点包含坐标
    /// 3. 子节点按 z-index 降序排列后递归检查（高 z-index 优先命中，
    ///    无 z-index 时按 child 索引递增作为默认值，与 SceneGraph 的
    ///    z-order 排序一致）
    /// 4. 返回最深匹配
    pub fn hit_test(&self, point: Point) -> Option<WidgetId> {
        self.hit_test_recursive(self.root(), point)
    }

    fn hit_test_recursive(&self, widget_id: WidgetId, point: Point) -> Option<WidgetId> {
        let bounds = self.bounds.get(&widget_id)?;
        if !bounds.contains(point) { return None; }

        if let Some(children) = self.children.get(&widget_id) {
            // 按 z-index 降序排列子节点（z-order 与 SceneGraph 一致）
            let mut sorted: Vec<_> = children.iter().copied().collect();
            sorted.sort_by_key(|&id| {
                // 从 widget props 读取 z-index，无则用 0（与 scene_build 一致）
                self.z_index(id).unwrap_or(0)
            });
            for child in sorted.into_iter().rev() {
                if let Some(hit) = self.hit_test_recursive(child, point) {
                    return Some(hit);
                }
            }
        }
        Some(widget_id)
    }

    fn z_index(&self, _widget_id: WidgetId) -> Option<i32> { /* 从 props 或 SceneGraph 读取 */ None }

    pub fn root(&self) -> WidgetId { /* 返回 widget 树的根节点 ID */ todo!() }

    pub fn traverse_visual_order(&self) -> Vec<WidgetId> { /* DFS 遍历产生视觉序列表 */ todo!() }
}
```

**性能优化**：缓存最近命中测试结果（鼠标连续移动）；> 500 节点时使用 R-tree 空间索引；虚拟滚动容器只检查可见子节点。

```rust
    /// Tab 前进到下一个可聚焦 widget。
    pub fn tab_forward(&mut self) { /* 在 tab_order 中循环 */ }

    /// Shift+Tab 后退。
    pub fn tab_backward(&mut self) { /* 反向循环 */ }

    /// 推送焦点作用域（打开模态）。
    pub fn push_scope(&mut self, scope_root: WidgetId) {
        self.focus_restore.push(self.current_focus.unwrap_or(scope_root));
        self.focus_scope.push(scope_root);
    }

    /// 弹出焦点作用域（关闭模态）。
    pub fn pop_scope(&mut self) {
        self.focus_scope.pop();
        if let Some(restore) = self.focus_restore.pop() {
            self.focus(restore, FocusSource::Programmatic);
        }
    }

    /// 重建 Tab 序（布局变更后）。
    pub fn rebuild_tab_order(&mut self, tree: &WidgetTree) {
        self.tab_order = tree.traverse_visual_order()
            .into_iter()
            .filter(|&id| self.is_focusable(id))
            .collect();
    }
}
```

### 5.2 焦点策略

| 场景 | 行为 |
|------|------|
| 点击可聚焦 widget | 设置焦点（Mouse 源） |
| Tab | 按 tab_order 移动到下一个 |
| Shift+Tab | 按 tab_order 移动到上一个 |
| 打开模态 | 焦点移入对话框，旧焦点保存 |
| 关闭模态 | 焦点恢复 |

```rust
/// 判断候选矩形是否在指定方向上。
fn is_in_direction(current: Rect, candidate: Rect, dir: Direction) -> bool { /* 方向判断 */ true }

/// 两个矩形之间的最短距离。
fn distance(a: Rect, b: Rect) -> f32 { /* 曼哈顿距离或欧几里得距离 */ 0.0 }

impl SpatialNavigation {
    pub fn find_nearest(
        current: Rect, direction: Direction,
        candidates: &[(WidgetId, Rect)],
    ) -> Option<WidgetId> {
        candidates.iter()
            .filter(|(_, rect)| is_in_direction(current, *rect, direction))
            .min_by_key(|(_, rect)| distance(current, *rect))
            .map(|(id, _)| *id)
    }
}
```

## 7. IME 集成

```rust
/// IME 管理器。
pub struct ImeManager {
    enabled: bool,
    preedit_text: String,
    preedit_cursor: usize,
    candidate_position: Point,
}

impl ImeManager {
    pub fn enable(&mut self, cursor_position: Point) {
        self.enabled = true;
        self.candidate_position = cursor_position;
    }

    pub fn disable(&mut self) {
        self.enabled = false;
        self.preedit_text.clear();
    }

    pub fn handle_preedit(&mut self, text: String, cursor_offset: usize) -> String {
        self.preedit_text = text.clone();
        self.preedit_cursor = cursor_offset;
        text
    }

    pub fn handle_commit(&mut self, text: String) -> String {
        let committed = text.clone();
        self.preedit_text.clear();
        self.preedit_cursor = 0;
        committed
    }
}
```

## 9. 平台事件映射

```rust
/// 将 winit 事件转换为框架 Event。
pub fn convert_winit_event(
    event: winit::event::WindowEvent,
    mouse_pos: Point,
    scale_factor: f64,
) -> Option<Event> {
    match event {
        winit::event::WindowEvent::MouseInput { state, button, .. } => {
            let btn = convert_button(button);
            let modifiers = Modifiers::current();
            match state {
                winit::event::ElementState::Pressed => {
                    Some(Event::MouseDown { position: mouse_pos, button: btn, modifiers })
                }
                winit::event::ElementState::Released => {
                    Some(Event::MouseUp { position: mouse_pos, button: btn, modifiers })
                }
            }
        }
        winit::event::WindowEvent::CursorMoved { position, .. } => {
            Some(Event::MouseMove {
                position: Point { x: position.x / scale_factor as f32, y: position.y / scale_factor as f32 },
                delta: Point { x: 0.0, y: 0.0 }, modifiers: Modifiers::current(),
            })
        }
        winit::event::WindowEvent::KeyboardInput { event, .. } => {
            let key = convert_key(event.physical_key);
            match event.state {
                winit::event::ElementState::Pressed => Some(Event::KeyDown {
                    key, modifiers: Modifiers::current(), repeat: event.repeat,
                }),
                winit::event::ElementState::Released => Some(Event::KeyUp {
                    key, modifiers: Modifiers::current(),
                }),
            }
        }
        winit::event::WindowEvent::Ime(ime) => convert_ime(ime),
        winit::event::WindowEvent::MouseWheel { delta, .. } => {
            Some(Event::MouseWheel {
                position: mouse_pos,
                delta: convert_scroll_delta(delta),
                modifiers: Modifiers::current(),
            })
        }
        winit::event::WindowEvent::Resized(size) => {
            Some(Event::WindowResized { width: size.width as f64, height: size.height as f64 })
        }
        winit::event::WindowEvent::Focused(focused) => {
            if focused { Some(Event::WindowFocused) } else { Some(Event::WindowUnfocused) }
        }
        winit::event::WindowEvent::CloseRequested => Some(Event::CloseRequested),
        _ => None,
    }
}
```

## 10. 边界情况处理

| 情况 | 处理 |
|------|------|
| 鼠标在 widget 边界上 | 包含上/左边界，不含右/下边界（CSS 一致） |
| 组合键冲突 | 框架快捷键仅当窗口获得焦点时生效 |
| 焦点 widget 被移除 | 清除焦点，尝试聚焦最近兄弟节点 |
| IME 在非文本 widget | 禁用 IME，忽略 IME 事件 |
| 多点触控 | 主触控点走鼠标事件路径，其他走 Gesture 事件（阶段 2） |
