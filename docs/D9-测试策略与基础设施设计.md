## 3. 覆盖策略

| 关注点 | 测试方式 |
|--------|----------|
| `WidgetSpec` 生命周期 | 单元/集成（`core_loop.rs`：view→update→view；`d10_components.rs`：组件行为） |
| 状态差分 `diff`/`apply_patch` | 单元（`state/diff.rs`：roundtrip 收敛——deep child change / add child subtree / remove child / sibling props） |
| 布局 | 集成（`layout_engine.rs`：Taffy compute）；`LayoutResult` 重建 rect 单元 |
| 渲染（离屏） | `--all-features` 像素断言（vello 离屏） |
| 字形（真实） | `--all-features` `shapes_ascii_text_into_glyphs_and_valid_font` |
| fire 防火墙/DAG | 静态检查（`rgui-core/Cargo.toml` 无 render/platform/macros/winit/wgpu/vello/cosmic-text）+ `cargo check` |
| 可视化 | **截图验证**（见 §4） |
| **测试信号日志分层（D22）** | D21 测试信号（`[hit-region]`/`[win-frame]`/`[mouse-event]`/`[action]` 等）经 `tracing::info!(target="rgui_test_signal")` 输出到 **stdout**——纯裸 message（原 token，无级别/时间戳前缀，D21 脚本正则**零改动**）；库日志→**stderr**（带级别/时间戳，开发者排障）。`RUST_LOG=rgui_test_signal=info` 只出测试信号（库日志关）、`RUST_LOG=off` 全关；级别默认 `info`。**测试信号与库日志物理分层**（rgui/src/logging.rs `init_logging()`）。 |

## 4. 截图验证方法（用户硬约束）

**可视化验证必须靠实际截图证明（渲染到窗口真实可见），发布工单前先测试截图；截图作为验收证据递交。**

- 位置：`tools/qa/d7_screenshots/`（`d10_final_collapsed.png` / `d10_final_expanded.png` / `d10_accordion_collapsed_verified.png`）。
- `--expanded` CLI 参数（`cargo run ... --example window_demo -- --expanded`）绕过 macOS 辅助功能权限，生成收起/展开两态截图对比（qa 按窗口 ID 截取）。
- 验收：收起/展开两态像素级对比 + 交互切换（点击/Space）前后对比。

## 5. 门禁命令

| 命令 | 用途 |
|------|------|
| `cargo test --workspace --all-features` | 全量测试（D10 验收 45 全绿） |
| `cargo check --workspace` | 默认构建检查（platform `default=["winit"]` 通过） |
| `cargo fmt -- --check` | 格式检查 |
| `cargo clippy` | clippy（核心安全类 `-D`；unwrap/todo/expect 放宽） |
| `cargo check --workspace --features window` | 含窗口+渲染构建检查 |

**lint 门禁**：`unsafe_code = deny`（唯一强制）+ `cargo test` + `cargo fmt --check`；clippy 仅核心安全类 `-D`。

## 6. 基础设施

- **测试组件**：`Counter`（`core_loop.rs`/`demo.rs` 测试专用）——State=`CountState(u32)`、Message=`Increment`，覆盖核心循环。
- **布局/渲染**：`feature="layout"`（Taffy）/`vello-backend` 门控；默认构建离线、不引重型依赖。
- **TDD 铁律**：先写失败测试（RED）→ 实现（GREEN）→ 重构（REFACTOR）。每步有 RED 测试证据。
