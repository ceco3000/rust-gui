## 2. 单元测试策略

### 2.1 范围

纯 Rust crate：`rgui-core`（几何类型、PropValue、WidgetView）、`rgui-state`（StateStore、diff、快照）、`rgui-style`（选择器、属性解析、变量）、`rgui-layout`（CSS→Taffy 映射）。

### 2.2 测试模式

遵循 AAA（Arrange-Act-Assert）模式。边界情况必须覆盖：空状态、极值、类型不匹配。

```rust
#[test]
fn test_diff_no_change() {
    let old = WidgetView::new("Button").prop("text", PropValue::Str(Arc::from("点击")));
    let new = old.clone();
    let parent_id = WidgetId::new(1);
    let mut id_map = WidgetIdMap::new();
    let patches = diff(&old, &new, parent_id, &mut id_map);
    assert!(patches.is_empty());
}
```

## 4. 离屏渲染测试 Runner

不依赖窗口系统和 GPU 显示输出的渲染测试器：

```rust
pub struct OffscreenTestRunner {
    device: wgpu::Device,
    queue: wgpu::Queue,
    backend: VelloBackend,
    width: u32, height: u32,
}

impl OffscreenTestRunner {
    pub fn new(width: u32, height: u32) -> Self { /* wgpu 设备 + 离屏纹理 */ }

    /// 渲染到离屏纹理，返回 RGBA 像素。
    pub fn render(&mut self, scene: &SceneGraph) -> Vec<u8> { /* ... */ }

    /// 渲染并保存 PNG。
    pub fn render_to_png(&mut self, scene: &SceneGraph, path: &Path) { /* image crate */ }
}
```

**CI 无 GPU 策略**：优先使用 lavapipe（Vulkan 软件实现）；备选使用 Skia CPU 光栅化（AV2 已验证）。

## 5. 截图回归测试

流程：首次运行保存基准 PNG → 后续运行生成当前 PNG → 像素级 diff → 差异像素数 < 总像素的 0.5%（容忍抗锯齿差异）。

```rust
pub fn assert_screenshot_matches(
    runner: &mut OffscreenTestRunner, scene: &SceneGraph, test_name: &str,
) {
    let baseline = PathBuf::from("tests/screenshots/baseline").join(format!("{}.png", test_name));
    let actual = PathBuf::from("tests/screenshots/actual").join(format!("{}.png", test_name));
    runner.render_to_png(scene, &actual);

    if baseline.exists() {
        let diff_ratio = pixel_diff_ratio(&baseline, &actual);  // 逐像素比较，返回不同像素占比
        assert!(diff_ratio < 0.005, "截图回归失败：{:.2}% 像素不同", diff_ratio * 100.0);
    } else {
        std::fs::copy(&actual, &baseline).unwrap();
    }
}
```

## 7. CI 矩阵

```yaml
# GitHub Actions 矩阵
os: [ubuntu-latest, macos-latest, windows-latest]
rust: [1.85, stable]

jobs:
  - test (workspace excl. render)
  - test-render (--features offscreen)
  - coverage (cargo llvm-cov → Codecov)
  - screenshots
  - lint (clippy, fmt, doc)
```

| 维度 | 选项 | 原因 |
|------|------|------|
| OS | Win/Mac/Linux | 三平台 |
| Rust 版本 | 1.85 + stable | MSRV 保证 |
| GPU | 有/无 | 降级验证 |

## 8. 覆盖率目标与工具

| crate | 行覆盖率 | 分支覆盖率 |
|-------|---------|-----------|
| `rgui-core` | ≥ 90% | ≥ 85% |
| `rgui-state` | ≥ 85% | ≥ 80% |
| `rgui-layout` | ≥ 85% | ≥ 80% |
| `rgui-style` | ≥ 80% | ≥ 75% |
| `rgui-render` | ≥ 75% | ≥ 70% |
| `rgui-platform` | ≥ 70% | ≥ 65% |
| `rgui-a11y` | ≥ 80% | ≥ 75% |
| `rgui` facade | ≥ 70% | ≥ 65% |
| **整体** | **≥ 80%** | **≥ 75%** |

工具：`cargo-llvm-cov`（LLVM source-based coverage），lcov.info → Codecov。

**CI 门禁**：PR 整体覆盖率不下降 > 1%；新文件 ≥ 80%；核心 crate 不设下降容忍。
