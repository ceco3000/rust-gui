## 5. `Patch` 差分补丁（`state/diff.rs`）

```rust
pub enum Patch<M> {
    SetProps(PropValue),                       // 替换当前节点 props
    SetChildProps { index: usize, props: PropValue },  // 仅子节点 props 变
    ReplaceChild { index: usize, subtree: WidgetView<M> },  // 整棵替换子树
    InsertChild { index: usize, subtree: WidgetView<M> },   // 插入子树
    RemoveChild { index: usize },              // 删除子节点（超出尾部）
    MoveChild { from: usize, to: usize },      // D18 key-based：子节点按 key 移动复用
}
```

## 6. `diff` 算法

`pub fn diff<M: Clone>(a: &WidgetView<M>, b: &WidgetView<M>) -> Vec<Patch<M>>`

- **key-based reconcile（D18）**：当 children 全部带 `key` 时，`diff` 按 key 匹配复用——同 key 子节点**移动（`MoveChild`）+ 内容更新（`ReplaceChild`）**，而非按索引重建；b 独有 key → `InsertChild`，a 独有 key → `RemoveChild`。key 匹配使**删除/重排中间项不误伤邻位**（索引不 shift）。
- **位置型（position-based）**（children 无 key 或部分无 key 时）：对子节点**递归对比**。
  - 公共索引范围内子树不等价 → `ReplaceChild`（整棵替换为目标子树）。
- **收敛性**：`diff(a, b)` 后 `apply_patch(b, patches)` 收敛（`apply(diff(a,b)) == b`，含子节点结构域）。keyed + 位置型均收敛测试通过（`keyed_reorder_reuses_by_key`、`keyed_remove_middle_keeps_neighbors`、`keyed_add_remove_and_reorder_roundtrip_converges`）。
- **局限性已解决（P1-2）**：原位置型"子节点顺序交换按每处 differs replace"——D18 已实现 key-based reconcile（子节点带 `WidgetView.key` 标记复用 key）。
  - `b` 子节点更多 → `InsertChild`（携带完整子树内容）。
  - `a` 子节点更多 → `RemoveChild`（删除多余尾部）。
  - 根 props 变 → `SetProps`。
- **收敛性**：`diff(a, b)` 后 `apply_patch(b, patches)` 收敛（`apply(diff(a,b)) == b`，含子节点结构域）。
- **局限（P1-2 明确）**：为位置型，**无 key-based reconcile**：子节点顺序交换会被当作每处 differs（replace 而非最小移动）。key-based 排序 reconcile 留 D5。
