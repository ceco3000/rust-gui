## 2. 组件开发规范（实现 WidgetSpec）

实现一个新组件，需提供：

1. **状态类型** `State`：`impl PersistState`（`schema_name`/`schema_version`/`as_any`/`as_any_mut`）。
2. **消息类型** `Message`：`impl AppMessage`（`message_name`）。
3. **组件类型**：`impl WidgetSpec` 提供：
   - `name() -> &'static str`
   - `view(state, ctx) -> WidgetView<Self::Message>`（声明式构建视图树）
   - `update(msg, state, ctx)`（处理消息更新状态）
   - `measure(state, constraints, ctx) -> Size`
   - `paint(state, bounds, ctx)`（可空）
   - `focusable()`（默认 `false`，可覆写 `true` 声明可获焦，Tab 导航）
   - `accessibility(...)`（可覆写，默认 `none()`）

**约定**：组件应为 `Send + Sync + 'static`；用 `PropValue::Color`/`PropValue::Str` 表达视图图元；用 `size` 建议尺寸供 `LayoutEngine`/`SceneGraph::from_view` 布局。

## 3. 内置组件（`rgui-core/src/components.rs`）

### 3.1 `Accordion`（折叠/展开容器）

| 项 | 定义 |
|----|------|
| 消息 | `AccordionMsg::Toggle`（`message_name`="accordion.toggle"） |
| 状态 | `AccordionState { title, subtitle, expanded }`（默认收起；`schema_name`="accordion_state"） |
| view | 根 340×content_h（展开 130 / 收起 44）；header 用 `Color::rgb(90,130,220)` 背景（固定），title 用 `Str("{title} [+/-]")`、size 320×28，展开时追加 content（`Str("⌄ {subtitle}")`、size 340×84）；**获焦描边**：`root.border = Border::new(Color::rgb(255,230,80), 3.0)`（D16 亮黄外框，外扩 2px）；**文本可用宽**：title/content 的 `size.width` 供 `DrawText.width` 换行（D17，如 title=320、content=340） |
| update | `Toggle` → 翻转 `state.expanded` |
| measure | 展开 340×130 / 收起 340×44 |
| focusable | `true`（可获焦，Tab 导航） |
| paint | 空 |

### 3.2 `WaBadge`（徽章/标签）

| 项 | 定义 |
|----|------|
| 消息 | `WaBadgeMsg::Click`（`message_name`="wa_badge.click"；点击计数） |
| 状态 | `WaBadgeState { label, count }`（`schema_name`="wa_badge_state"） |
| view | 根 160×40，`Color::rgb(120,160,210)` 背景（固定）；label 用 `Str("{label}: {count}")`、size 150×26；**获焦描边**：`root.border = Border::new(Color::rgb(255,230,80), 3.0)`（D16 亮黄外框，外扩 2px）；**文本可用宽**：label 的 `size.width`（150）供 `DrawText.width` 换行（D17） |
| update | `Click` → `state.count += 1` |
| measure | 160×40 |
| focusable | `true`（可获焦，Tab 导航） |
| paint | 空 |

## 4. 可运行示例（`rgui/examples/`）

| 示例 | 说明 | 运行 |
|------|------|------|
| `window_demo.rs` | 真实交互 Accordion：窗口弹出即渲染，点击标题/Space 切换展开/收起；`-- --expanded` 初始展开 | `cargo run -p rgui --features window --example window_demo` |
| `demo.rs` | 核心循环闭环：Counter 经 `Coordinator` 驱动 view→update→view + diff + Snapshot | `cargo run -p rgui --example demo` |

**`window_demo.rs` 关键点**：
- `#![cfg(feature = "window")]`
- `App::run(config, Accordion, state, mapper)`（`config.with_title(...).with_size(480, 320)`）
- `mapper` 把 `MouseInput(Left,Pressed)` / `KeyboardInput(Space)` 映射为 `AccordionMsg::Toggle`
- `state = AccordionState { title:"Settings", subtitle:"WaBadge: 0 ...", expanded }`
