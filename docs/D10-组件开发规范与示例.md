## 1. 组件开发流程总览

```
1. 定义 State + Message 类型
2. 实现 WidgetSpec trait（view / update / measure / paint / accessibility）
3. 定义默认样式（.rgss）
4. 编写测试（单元 + 截图回归 + 无障碍）
5. 注册组件（App::register::<T>()）
6. 编写使用文档
```

## 2. 第 1 步：定义状态与消息类型

```rust
use rgui_core::{PersistState, AppMessage};

/// Button 业务状态。
#[derive(Debug, Clone, Default, PersistState)]
#[state(schema = "rgui_components::WaButtonState", version = 1)]
pub struct WaButtonState {
    pub label: String,
    pub disabled: bool,
    pub pressed: bool,
}

/// Button 消息。
#[derive(Debug, Clone, AppMessage)]
pub enum WaButtonMessage {
    Clicked,
    FocusGained,
    FocusLost,
}
```

**规范要点**：
- `State` 必须实现 `PersistState`，含 `schema_name` 和 `schema_version`
- `State` 不得包含 GPU/平台资源句柄
- `Message` 必须实现 `AppMessage`，每个变体对应一种用户交互
- 推荐使用 `#[derive(PersistState)]` 和 `#[derive(AppMessage)]` 派生宏

## 3. 第 2 步：实现 WidgetSpec trait

```rust
use rgui_core::{
    WidgetSpec, WidgetView, ViewContext, UpdateContext,
    MeasureContext, PaintContext, AccessContext,
    Rect, Size, BoxConstraints, Color, DrawCommand,
    AccessibilityNode, AccessibilityRole, AccessibilityAction, AccessibilityState,
};

pub struct WaButton;

impl WidgetSpec for WaButton {
    type State = WaButtonState;
    type Message = WaButtonMessage;

    fn name(&self) -> &'static str { "rgui_components::WaButton" }

    fn view(&self, state: &Self::State, ctx: &ViewContext) -> WidgetView<Self::Message> {
        WidgetView::new("rgui_components::WaButton")
            .prop("label", PropValue::Str(state.label.clone().into()))
            .prop("disabled", PropValue::Bool(state.disabled))
            .child(
                WidgetView::new("rgui_core::Text")
                    .prop("content", PropValue::Str(state.label.clone().into()))
            )
    }

    fn update(
        &self, msg: Self::Message, state: &mut Self::State, ctx: &mut UpdateContext,
    ) {
        match msg {
            WaButtonMessage::Clicked => {
                if !state.disabled {
                    // 向父组件发送消息（消息类型为应用层定义的 AppMessage 变体）
                    // ctx.event_sender.send_to_parent(MyAppMessage::ButtonClicked);
                }
            }
            WaButtonMessage::FocusLost => { state.pressed = false; }
            _ => {}
        }
    }

    fn measure(
        &self, state: &Self::State, constraints: BoxConstraints, ctx: &MeasureContext,
    ) -> Size {
        let font_size = 14.0;
        let text_width = state.label.len() as f64 * font_size * 0.6;
        let width = (text_width + 32.0).max(64.0).min(constraints.max_width());
        let height = 32.0.min(constraints.max_height());
        Size::new(width, height)
    }

    fn paint(&self, state: &Self::State, bounds: Rect, ctx: &mut PaintContext) {
        let color = if state.disabled {
            Color::rgba(156, 163, 175, 255)
        } else if state.pressed {
            Color::rgba(37, 99, 235, 255)
        } else {
            Color::rgba(59, 130, 246, 255)
        };
        // paint() 返回 Vec<DrawCommand>，由框架并入 SceneGraph
        let _commands = vec![
            DrawCommand::FillRect { rect: bounds, color, radius: 6.0 },
            // DrawCommand::DrawGlyphs { ... }  // 字形数据从 ctx.glyph_atlas 获取
        ];
        // 实际实现见 D3 §3.1 DrawCommand 枚举
    }

    fn accessibility(
        &self, state: &Self::State, ctx: &AccessContext,
    ) -> AccessibilityNode {
        AccessibilityNode {
            role: AccessibilityRole::Button,
            name: state.label.clone(),
            description: String::new(),
            value: None,
            states: vec![if state.disabled { AccessibilityState::Disabled } else { AccessibilityState::Enabled }],
            actions: vec![AccessibilityAction::Activate],
            children: vec![],
            bounds: None,
        }
    }
}
```

**规范要点**：
- `view()` 是纯函数，无副作用
- `update()` 只修改自身状态，向父组件发消息用 `event_sender`
- `measure()` 尊重 `BoxConstraints`（min/max）
- `paint()` 使用 `ctx.push_command()` 而非自行管理 SceneGraph
- `accessibility()` 必须设置 role/name/actions

## 4. 第 3 步：定义默认样式

```css
/* components/button.rgss */
WaButton {
    font-size: 14px;
    font-weight: 500;
    border-radius: 6px;
    padding: 8px 16px;
    min-width: 64px;
    min-height: 32px;
    background-color: var(--color-primary);
    color: #FFFFFF;
    cursor: pointer;
}

WaButton:hover { opacity: 0.9; }
WaButton:pressed { background-color: var(--color-primary-hover); }
WaButton[disabled] { background-color: var(--color-disabled); opacity: 0.5; cursor: default; }
WaButton:focus-visible { outline: 2px solid var(--color-primary); outline-offset: 2px; }
```

**规范要点**：使用主题变量（`var(--xxx)`）而非硬编码颜色；覆盖关键状态（`:hover`、`:focus-visible`、`[disabled]`）。

## 5. 第 4 步：编写测试

### 5.1 单元测试

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_button_view() {
        let button = WaButton;
        let state = WaButtonState { label: "点击".into(), disabled: false, pressed: false };
        let ctx = create_test_view_context();
        let view = button.view(&state, &ctx);
        assert_eq!(view.widget_type, "rgui_components::WaButton");
        assert_eq!(view.children.len(), 1);
    }

    #[test]
    fn test_button_disabled_no_click() {
        let button = WaButton;
        let mut state = WaButtonState { label: "点击".into(), disabled: true, pressed: false };
        let mut ctx = create_test_update_context();
        button.update(WaButtonMessage::Clicked, &mut state, &mut ctx);
        assert!(ctx.event_sender.events().is_empty());
    }

    #[test]
    fn test_button_measure_min_size() {
        let button = WaButton;
        let state = WaButtonState::default();
        let ctx = create_test_measure_context();
        let size = button.measure(&state, BoxConstraints::loose(800.0, 600.0), &ctx);
        assert!(size.width >= 64.0);
        assert!(size.height >= 32.0);
    }

    #[test]
    fn test_button_accessibility() {
        let button = WaButton;
        let state = WaButtonState { label: "提交".into(), ..Default::default() };
        let ctx = AccessContext { visible_bounds: Rect::ZERO, focus_path: vec![] };
        let node = button.accessibility(&state, &ctx);
        assert_eq!(node.role, AccessibilityRole::Button);
        assert_eq!(node.name, "提交");
        assert!(node.actions.contains(&AccessibilityAction::Activate));
    }
}
```

## 9. 组件开发检查清单

- [ ] **State**：实现 `PersistState`；不含 GPU/平台资源；字段文档齐全
- [ ] **Message**：实现 `AppMessage`；每个变体对应一种交互
- [ ] **view()**：纯函数；从 `&State` 派生 `WidgetView`；无副作用
- [ ] **update()**：只修改自身状态；通过 `EventSender` 与外界通信
- [ ] **measure()**：尊重 `BoxConstraints`；返回合理最小/最大尺寸
- [ ] **paint()**：使用 `PaintContext`；生成正确 `DrawCommand`
- [ ] **accessibility()**：设置 role/name/actions；禁用状态正确
- [ ] **默认样式**：`.rgss` 文件；使用主题变量；覆盖关键状态
- [ ] **单元测试**：view/update/measure/accessibility ≥ 80% 覆盖率
- [ ] **截图测试**：每个视觉状态（默认/禁用/悬停/焦点）≥ 1 截图
- [ ] **无障碍测试**：role/name/actions 验证
- [ ] **错误状态**：空文本/超长文本/禁用等情况有合理行为
- [ ] **文档**：README 含使用示例、属性表、消息类型表

## 10. Tier 2：脚本定义组件

> **适用场景**：应用层定制 UI、业务组件、频繁修改的视图。不需要 Rust 编译，修改 `.rgui`/`.rhai` 秒级生效。当需要最大性能、新渲染原语或调用底层 API 时，走 Tier 1（§1-§9）。

### 10.1 开发流程

```
1. 创建 .rgui 文件 —— 声明组件树结构
2. 创建 .rhai 文件 —— 编写 paint 函数 + 事件处理器
3. 在父组件 .rgui 中引用该组件标签
4. 热重载自动生效，无需 cargo build
```

### 10.2 完整示例：自定义卡片组件

**文件结构：**

```
my-page/
├── ui.rgui              ← 使用卡片
├── handlers.rhai
├── my_card.rgui         ← 卡片组件定义（与 .rhai 同级）
└── my_card.rhai         ← 卡片 paint 脚本（与 .rgui 同级）
```

**my_card.rgui**（组件结构）：

```xml
<Container id="root">
  <Container id="header">
    <Text id="title" text="{title}" />
  </Container>
  <Container id="body">
    <slot />
  </Container>
</Container>
```

**my_card.rhai**（paint 脚本，加载时执行一次）：

```rust
fn paint_card(bounds, props, children) {
    let bg = props.get("background").unwrap_or(rgb(1.0, 1.0, 1.0));
    let border_color = props.get("border-color").unwrap_or(rgb(0.85, 0.85, 0.85));
    let radius = props.get("radius").unwrap_or(8.0);

    // 背景填充
    fill_rect(bounds.x, bounds.y, bounds.w, bounds.h, bg, radius);

    // 1px 边框
    fill_rect(bounds.x, bounds.y, bounds.w, 1.0, border_color, 0.0);
    fill_rect(bounds.x, bounds.y + bounds.h - 1.0, bounds.w, 1.0, border_color, 0.0);
    fill_rect(bounds.x, bounds.y, 1.0, bounds.h, border_color, 0.0);
    fill_rect(bounds.x + bounds.w - 1.0, bounds.y, 1.0, bounds.h, border_color, 0.0);

    // 递归绘制子节点
    paint_children(children);
}

// 事件处理
fn on_title_click() {
    set_prop("root", "expanded", !get_prop("root", "expanded"));
}
```

**ui.rgui**（使用卡片）：

```xml
<Column gap="16">
  <my_card title="Card 1" background="rgb(0.98, 0.98, 0.98)">
    <Text text="Content of Card 1" />
  </my_card>
  <my_card title="Card 2" radius="4.0">
    <Text text="Content of Card 2" />
  </my_card>
</Column>
```

### 10.3 可用的原生函数

| 函数 | 说明 |
|------|------|
| `fill_rect(x, y, w, h, color, radius)` | 填充矩形 |
| `draw_text(text, x, y, w, h, color, font_size)` | 绘制文本 |
| `rgb(r, g, b)` / `rgba(r, g, b, a)` | 构造颜色 |
| `paint_children(children)` | 递归绘制子节点 |
| `get_prop(id, key)` / `set_prop(id, key, value)` | 读写 prop |
| `to_int(v)` / `to_float(v)` / `to_string(v)` | 类型转换 |
| `log_info(msg)` / `log_warn(msg)` | 日志 |

### 10.4 Tier 2 检查清单

- [ ] **.rgui**：组件树结构完整；子节点用 `<slot />` 声明插槽；缺少 `<slot />` 时子节点内容被丢弃（日志警告）；根节点非 Container 时自动包裹默认 Container
- [ ] **paint 函数**：加载时执行一次生成 PaintOp；调用 `paint_children(children)` 递归子节点
- [ ] **事件处理**：通过 `get_prop`/`set_prop` 读写状态；无 I/O、无重计算
- [ ] **错误处理**：脚本语法错误时保留上一版 PaintOp；参数越界自动 clamp
- [ ] **热重载**：修改 .rgui 或 .rhai 后秒级生效，Rust 进程不重启
- [ ] **性能**：单次 paint 脚本执行 < 1ms；热路径纯 Rust 消费 PaintOp
- [ ] **无障碍**：组件内容文本通过 `draw_text` 渲染后，框架自动生成基础 `AccessibilityNode`（role=group，label 取自首个 Text 子节点）。复杂无障碍需求走 Tier 1
