## 1. 定位

无障碍系统收敛为 `rgui-core::a11y`（纯 Rust 类型）+ `a11y_tree`（树结构）。**AccessKit 桥（backend.rs）已删除**（契约 §4 R1）：重型跨平台依赖无消费方，删；纯类型保留并入核心。

---

## 2. 无障碍基础类型（`a11y.rs`）

```rust
pub enum AccessibilityRole { Unknown, Button, Text, Container }
pub enum AccessibilityAction { Activate, Focus, Blur }
pub struct AccessibilityState { pub focusable: bool, pub focused: bool }
pub struct AccessibilityNode { pub role: AccessibilityRole, pub label: String, pub state: AccessibilityState }
impl AccessibilityNode { pub fn new() -> Self; pub fn none() -> Self }
```

| 类型 | 状态 |
|------|------|
| `AccessibilityRole` | 实现（Unknown 默认 / Button / Text / Container） |
| `AccessibilityAction` | 实现（Activate / Focus / Blur） |
| `AccessibilityState { focusable, focused }` | 实现 |
| `AccessibilityNode { role, label, state }` | 实现；`new()` / `none()`（对齐 greenfield §B.1） |

---

## 3. 无障碍树（`a11y_tree.rs`）

```rust
pub struct AccessibilityTree { pub root: Option<AccessibilityTreeNode> }
pub struct AccessibilityTreeNode { pub widget_id: WidgetId, pub node: AccessibilityNode, pub children: Vec<AccessibilityTreeNode> }
```

- 由 `rgui-a11y/tree.rs` 迁入；`AccessibilityTree::new()`（空树）。

---

## 4. 与 `WidgetSpec` 的接线

`WidgetSpec::accessibility(&self, _s, _c) -> AccessibilityNode`（默认返回 `AccessibilityNode::none()`，可覆写产出角色/标签/状态）。`Accordion`/`WaBadge` 当前未覆写（默认 `none()`）。
