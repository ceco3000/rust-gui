## 1. 设计目标与范围

### 1.1 本文档解决什么问题

1. 定义无障碍树的生成算法（遍历 widget 树 → 收集 AccessibilityNode）
2. 定义 AccessKit 集成方案（rgui 无障碍树 → AccessKit TreeUpdate → 平台原生 API）
3. 定义 `AccessibilityBackend` trait（支持 AccessKit 和未来其他后端）
4. 定义 WCAG 2.1 AA 要求到框架实现的具体映射

### 1.2 设计原则

1. **自动生成**：无障碍树由框架自动维护，组件只需实现 `accessibility()` 返回描述
2. **增量更新**：仅变更的 widget 重新生成 AccessibilityNode
3. **平台适配**：通过 AccessKit 桥接到平台原生无障碍 API（macOS NSAccessibility、Windows UI Automation、Linux AT-SPI2）

## 2. 无障碍树生成算法

### 2.1 基础类型（定义于 rgui-core）

```rust
#[derive(Debug, Clone)]
pub struct AccessibilityNode {
    pub role: AccessibilityRole,
    pub name: String,
    pub description: String,
    pub value: Option<String>,
    pub states: Vec<AccessibilityState>,
    pub actions: Vec<AccessibilityAction>,
    pub children: Vec<AccessibilityNode>,
    pub bounds: Option<Rect>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AccessibilityRole {
    Button, TextField, CheckBox, RadioButton,
    Link, Image, Heading, List, ListItem,
    Table, Row, Cell, ColumnHeader, RowHeader,
    Menu, MenuItem, MenuBar, Tab, TabList, TabPanel,
    Dialog, AlertDialog, Slider, ProgressBar, Tooltip,
    ScrollBar, ScrollView, Group, Pane, Window,
    StaticText, Label, Separator, GenericContainer, None,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AccessibilityState {
    Focused, Focusable, Enabled, Disabled,
    Selected, Selectable, Checked, Checkable,
    Expanded, Collapsed, Visible, Hidden,
    Pressed, Required, Invalid, Multiline, ReadOnly,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AccessibilityAction {
    Focus, Activate, Increment, Decrement,
    ScrollByPage, ScrollTo, SetValue, Select,
    Expand, Collapse, SortByColumn, ShowContextMenu,
}

impl AccessibilityNode {
    /// 返回空无障碍节点（用于无特殊无障碍需求的组件）。
    pub fn none() -> Self {
        AccessibilityNode {
            role: AccessibilityRole::GenericContainer,
            name: String::new(), description: String::new(),
            value: None, states: vec![], actions: vec![],
            children: vec![], bounds: None,
        }
    }
}
```

### 2.2 树构建算法

```rust
pub struct AccessibilityTree {
    root: AccessibilityNode,
    prev_nodes: FxHashMap<WidgetId, AccessibilityNode>,
    current_nodes: FxHashMap<WidgetId, AccessibilityNode>,
}

impl AccessibilityTree {
    /// 从 widget 树重建无障碍树（DFS 遍历）。
    pub fn build(
        &mut self, widget_tree: &WidgetTree, state_store: &StateStore,
        registry: &WidgetRegistry, dirty_widgets: &FxHashSet<WidgetId>,
    ) {
        let root_id = widget_tree.root();
        let root_node = self.build_recursive(
            root_id, widget_tree, state_store, registry, dirty_widgets,
        );
        self.root = root_node;
    }

    fn build_recursive(
        &mut self, widget_id: WidgetId, widget_tree: &WidgetTree,
        state_store: &StateStore, registry: &WidgetRegistry,
        dirty_widgets: &FxHashSet<WidgetId>,
    ) -> AccessibilityNode {
        // 非 dirty 节点复用缓存
        if !dirty_widgets.contains(&widget_id) {
            if let Some(cached) = self.current_nodes.get(&widget_id) {
                return cached.clone();
            }
        }

        // 通过 StateStore + WidgetTree 获取状态和边界（详细 API 见 D2/D5）
        let state = state_store.read_persistent(widget_id);  // 见 D2 StoreAccess
        let bounds = widget_tree.bounds.get(&widget_id).copied().unwrap_or_default();
        let ctx = AccessContext {
            visible_bounds: bounds,
            focus_path: widget_tree.path_to_root(widget_id),  // 见 D5 WidgetTree
        };

        // 调用组件 accessibility() 方法（WidgetSpec trait，见 D1 §2.1）
        let mut node = /* widget.accessibility(state, &ctx) — 需从 Registry 获取组件实例后调用 */;
        node.bounds = Some(bounds);

        // 递归构建子节点
        if let Some(children) = widget_tree.children(widget_id) {
            node.children = children.iter()
                .map(|&child_id| self.build_recursive(
                    child_id, widget_tree, state_store, registry, dirty_widgets))
                .collect();
        }

        self.current_nodes.insert(widget_id, node.clone());
        node
    }

    /// 生成 AccessKit TreeUpdate（仅包含变更的节点）。
    pub fn diff_tree_update(&self) -> accesskit::TreeUpdate {
        let mut update = accesskit::TreeUpdate::default();
        for (&widget_id, new_node) in &self.current_nodes {
            let changed = match self.prev_nodes.get(&widget_id) {
                Some(old) => old != new_node,
                None => true,
            };
            if changed {
                update.nodes.push(to_accesskit_node(widget_id, new_node));
            }
        }
        update.tree = Some(accesskit::Tree::default());
        update
    }
}
```

## 3. AccessKit 集成

### 3.1 架构

```
rgui AccessibilityTree
  → diff_tree_update() → accesskit::TreeUpdate
  → AccessKit → macOS: NSAccessibility
              → Windows: UI Automation
              → Linux: AT-SPI2
  → VoiceOver / NVDA / Orca 等屏幕阅读器
```

### 3.2 角色映射

| rgui AccessibilityRole | accesskit::Role |
|------------------------|-----------------|
| Button | Button |
| TextField | TextInput |
| CheckBox | CheckBox |
| RadioButton | RadioButton |
| Link | Link |
| Image | Image |
| Heading | Heading |
| List / ListItem | List / ListItem |
| Table / Row / Cell | Table / Row / Cell |
| Menu / MenuItem | Menu / MenuItem |
| Dialog | Dialog |
| Slider | Slider |
| ProgressBar | ProgressIndicator |
| StaticText | StaticText |
| Label | Label |
| Window | Window |
| None / GenericContainer | Unknown / GenericContainer |

### 3.3 集成代码

```rust
pub struct AccessKitBackend {
    node_ids: FxHashMap<WidgetId, accesskit::NodeId>,
    next_node_id: u64,
}

impl AccessKitBackend {
    /// rgui AccessibilityNode → accesskit::Node 转换。
    fn to_accesskit_node(id: WidgetId, node: &AccessibilityNode) -> accesskit::Node {
        accesskit::Node::new(to_accesskit_role(node.role))
            .set_name(node.name.clone())
            .set_description(node.description.clone())
        // 完整映射见 §3.2
    }

    pub fn push_update(&mut self, tree: &AccessibilityTree, adapter: &accesskit_winit::Adapter) {
        let update = tree.diff_tree_update();
        adapter.update(update);
    }
}
```

## 4. AccessibilityBackend trait

```rust
/// 无障碍后端抽象。
pub trait AccessibilityBackend: Send + Sync {
    /// 推送完整的无障碍树更新。
    fn push_tree(&mut self, tree: &AccessibilityTree);

    /// 推送焦点变更。
    fn focus_changed(&mut self, widget_id: WidgetId);

    /// 处理来自屏幕阅读器的操作请求（返回是否处理成功）。
    fn handle_action(&mut self, widget_id: WidgetId, action: AccessibilityAction) -> bool;

    /// 后端名称。
    fn backend_name(&self) -> &'static str;

    /// 通知实时区域（ARIA live region）内容变更。
    fn announce(&mut self, message: &str, priority: AnnouncePriority);
}

#[derive(Debug, Clone, Copy)]
pub enum AnnouncePriority { Low, Medium, High }
```

## 5. WCAG 2.1 AA 映射

### 5.1 逐条映射表

| WCAG 准则 | 框架实现 | 责任方 |
|-----------|---------|-------|
| **1.1.1 非文本内容** | `accessibility()` 返回 `name` + `description`，屏幕阅读器读取 | 设计覆盖 |
| **1.3.1 信息和关系** | `AccessibilityRole` 表达语义（Table/List/Heading 等） | 设计覆盖 |
| **1.3.2 有含义的序列** | 无障碍树 DFS 遍历 = 文档序；Tab 序由 FocusManager 定义 | 设计覆盖 |
| **1.4.1 颜色的使用** | 主题变量系统；框架不强制颜色传递信息 | 组件实现责任 |
| **1.4.3 对比度（最低）** | 默认主题文本/背景 ≥ 4.5:1，大文本 ≥ 3:1 | 默认主题覆盖 |
| **1.4.11 非文本对比度** | 默认主题 UI 组件边界 ≥ 3:1 | 默认主题覆盖 |
| **2.1.1 键盘** | 所有可交互组件通过 FocusManager 接收键盘事件 | 设计覆盖 |
| **2.1.2 无键盘陷阱** | FocusManager 模态焦点限制有明确出口（Esc 关闭） | 设计覆盖 |
| **2.4.3 焦点顺序** | Tab 序 = 视觉顺序（`rebuild_tab_order()`） | 设计覆盖 |
| **2.4.7 焦点可见** | 框架全局焦点指示器（2px 主色轮廓） | 设计覆盖 |
| **3.2.1 焦点** | 焦点变更不自动改变上下文 | 设计覆盖 |
| **3.2.2 输入** | 输入值变更由 update() 显式处理 | 设计覆盖 |
| **3.3.2 标签或说明** | `AccessibilityNode::name` 和 `description` | 组件实现责任 |
| **4.1.1 解析** | 无障碍树保证完整的父子引用 | 设计覆盖 |
| **4.1.2 名称、角色、值** | `AccessibilityNode` 必含 role/name | 设计覆盖 |

### 5.2 焦点指示器

框架在场景图生成阶段自动为持有焦点的 widget 追加 2px 主色轮廓边框（`DrawCommand::StrokePath`），不依赖组件自行实现。

## 6. 焦点与无障碍协同

```
FocusManager::focus(id)
  → StateStore 实例态标记
  → AccessibilityTree 标记节点 Focused
  → AccessibilityBackend::focus_changed(id)
  → AccessKit 推送 ACTION_FOCUS 事件
  → 屏幕阅读器读取 name/role/value
```

屏幕阅读器操作（如双击激活）反向路径：

```
屏幕阅读器 → AccessKit ACTION_CLICK → AccessibilityBackend::handle_action()
  → NodeId → WidgetId → 构造 Event → EventRouter::dispatch()
```

## 7. 边界情况处理

| 情况 | 处理 |
|------|------|
| 组件不实现 `accessibility()` | 派生宏返回 `AccessibilityNode::none()` → GenericContainer |
| 虚拟滚动大量行 | 仅生成可见行 + 缓冲行（±5）；报告虚拟行数给 AccessKit |
| 屏幕阅读器请求不可见区域 | 返回占位信息 |
| 模态对话框 | push_scope 时同步无障碍后端，限制屏幕阅读器读取范围 |
