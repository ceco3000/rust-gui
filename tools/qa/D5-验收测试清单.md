## 2. SceneGraph 从 WidgetView 转换（纯逻辑，A 层核心）

**目标**：`SceneGraph` 能正确把 `core::view::WidgetView<M>`（children/props 树）转成 draw 指令列表。

| ID | 用例 | Arrange | Act | Assert |
|----|------|---------|-----|--------|
| SG1 | 空视图转空场景图 | `WidgetView::empty()` | `SceneGraph::from_view(&v)` | scene root None 或空 draw 列表，无 panic |
| SG2 | 单矩形节点 | 一个含 Color prop 的 view | `from_view` | 产生 1 条 draw(Rect+Color) 指令，颜色正确 |
| SG3 | 文本节点 | 一个含 Str prop 的 view | `from_view` | 产生文本 draw 指令，text 内容匹配 |
| SG4 | 嵌套 children | 容器含 2 子节点 | `from_view` | draw 列表含 3 条（父1+子2），顺序与 children 一致 |
| SG5 | PropValue 类型映射 | Bool/Int/Float/Str/Color 各一 | `from_view` | 各类型正确映射到对应指令属性 |
| SG6 | 布局 rect 应用 | view 带 LayoutResult/Rect | `from_view` | draw 指令的 rect/position 取自布局结果 |
| SG7 | 只画不 opacity 默认 | 无特殊 prop | `from_view` | 默认 alpha/color 兜底正确，无 NaN |

---

### 2.1 draw 指令契约（dev 实现后应暴露）
`SceneGraph` 应含 `draws: Vec<DrawCmd>`（或等价），`DrawCmd` 至少含：`Rect{rect,color}`、`Text{text,pos,font,size,color}`、`Path`。**以 dev 实际契约 + greenfield §B.2 为唯一基准**微调断言。

## 3. 离屏渲染像素读回（B 层，契约锁定）

**目标**：vello 渲染到 CPU 图像（`ImageBuffer`/`Vec<u8>`），像素可读回。

| ID | 用例 | Arrange | Act | Assert |
|----|------|---------|-----|--------|
| PX1 | 空场景渲染尺寸一致 | 空 scene + 尺寸 W×H | `render_offscreen(scene, W, H)` | 返回图像尺寸 == W×H，全透明/背景色 |
| PX2 | 矩形渲染到指定色 | 红色矩形覆盖某区域 | render | 采样矩形中心像素 == 红色，到 alpha 容差 |
| PX3 | 文本渲染非空像素 | 文本 draw | render |文本覆盖区域有非透明像素（≠背景色） |
| PX4 | 背景透明/默认 | 无背景 draw | render | 空白区像素 alpha==0（或默认背景） |
| PX5 | 尺寸边界 | W/H=0 或极大 | render | 不 panic；0 尺寸合法为空图 |
| PX6 | 颜色容差 | 近似色 | render | 读回像素落在容差内（抗锯齿边缘除外，取核心像素） |

> ⚠️ 这些用例依赖 dev 暴露的离屏渲染 API（如 `VelloBackend::render_offscreen(&scene, w, h) -> CpuImage` 或 `render_to_image`）。API 名以 dev 实际为准。GPU 环境未就绪时跳过（`#[ignore]` 或环境检测），并在报告备注。

## 5. 依赖防火墙（core 零 GPU，静态）

| ID | 用例 | 判据 |
|----|------|------|
| FW1 | core 无 GPU 依赖 | `rgui-core/Cargo.toml [dependencies]` 不含 wgpu/vello/cosmic-text/fontdb/skrifa/render |
| FW2 | core 无 render/platform 引用 | core 源码无 `rgui_render`/`rgui_platform` 引用 |
| FW3 | render 只向下依赖 core | `rgui-render/Cargo.toml` 仅 `rgui-core.workspace=true`（+ GPU feature 内依赖），无 platform |
| FW4 | DAG 无环 | `cargo tree --workspace` 无 cycle |

> ⚠️ **P2 契约偏差（tasks.md:12 已记，D5 观察）**：core `default=["layout"]`，greenfield §D 要求 `default=[]`。taffy 纯 Rust 布局，**不违反**"零 GPU/零平台"防火墙语义，但违反"default 为空、重型隔离"的 feature 原则。建议 D5 由总监拍板：core default 改为 `[]`（taffy 经 `cargo test --features layout` 或依赖方 enable），或明确接受 `default=["layout"]`。**QA 不擅自改，上报。**

## 6. 增量编译：改 render 不重编 core（反向防火墙，实测）

| ID | 用例 | Act | Assert |
|----|------|-----|--------|
| INC1 | 改 render → core 不重编 | 向 `rgui-render/src/xxx.rs` 加注释 → `cargo check -p rgui-core` | core 主编译产物 rmeta SHA256 不变，未重编（参照 d3 §6 判据） |

> 说明：改 render 本就不应影响 core（core 不依赖 render）。此验证确认"反向无泄漏"——若 core 依赖 render 则会报错/重编。**操作只改注释，验证后 git 还原**。
