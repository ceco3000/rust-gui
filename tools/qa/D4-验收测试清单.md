## 0. 前提：测试对 dev 实现锁定的公开 API 契约

这几项是 D4 测试**能否编译**的前提接口（当前 core 为占位 stub，实现后必须暴露）：

- `rgui_core::state`：`StateStore<M>`、`InstanceState`（impl PersistState）、`StoreBinding`、`Subscription`、`Patch`（含`Diff`/`apply` 语义）、`Snapshot`、`Snapshotter`、`diff<M>(a,b)->Vec<Patch>`、`apply_patch..`
- `rgui_core::layout`：`LayoutEngine`（含 `compute_layout`/`set_root`/`new`）、`LayoutNode`、`LayoutResult{rect,size}`、`LayoutStyle`（映射来源）、`to_taffy_style(LayoutStyle)->Taffy Style`
- `rgui_core::registry`：`WidgetRegistry`（`register`/`get`/`insert`，`RegistryError{DuplicateId,NotFound}`）
- `rgui_core::components`：`Accordion`, `WaBadge`（impl WidgetSpec）
- `rgui_core::view`：`WidgetView<M>`（children/props）、`PropValue{Unit,Bool,Int,Float,Str,Color}`、`Color`
- `rgui_core::traits`：`AppMessage`、`PersistState`、`WidgetSpec`、`EventResult{Handled,Prevented,Continue(M)}`
- `rgui_core::geometry`：`BoxConstraints{min,max}`、`Size`、`Rect`
- `rgui_core::context`：`ViewContext`、`UpdateContext`、`MeasureContext`、`PaintContext`、`AccessContext`

> 注意：集成测试引用公开项一律用 `rgui_core::<模块>::<项>` 全路径，不依赖顶层 `prelude` 未导出项。

## 1. WidgetSpec 核心循环（view/update/paint + WidgetRegistry + WidgetNode 状态闭环）

**目标**：跑通「状态变化 → update → view 变更 → 重绘」最小闭环；注册表增删查正确。

### 1.1 视图/生命周期用例
| ID | 用例 | Arrange | Act | Assert |
|----|------|---------|-----|--------|
| W1 | 初始 view | `Counter{count:0}`；`WidgetSpec::view(&st,&ctx)` | 调 `view` | 返回 `WidgetView`，props/children 反映 count=0 |
| W2 | update 促发 view 变更 | 同 W1；`Counter` 消息 `Inc` | `update(Inc,&mut st,&mut ctx)` → 再 `view` | 新 view 反映 count=1 |
| W3 | update 幂等（空消息不改变） | 用 `NoopMsg` | `update(Noop,&mut st)` → `view` | view 与之前一致（count 不变） |
| W4 | measure 有界 | `BoxConstraints::loose()` | `measure(st,&bc,&mc)` | 返回 `Size`，width/height ≥0 且 ≤ f32::MAX |
| W5 | paint 不 panic | `Rect::new(0,0,100,100)` + `PaintContext` | `paint(st,&b,&mut ctx)` | 不 panic，正常返回 |
| W6 | accessibility 默认 none | 任意状态 | `accessibility(st,&ac)` | 返回 `AccessibilityNode` 默认（none/empty） |
| W7 | 组件协议（state/message 满足契约） | 编译期 | 编写 `fn _ck<S:PersistState,M:AppMessage>()` | 编译通过（关联类型满足 bound） |

### 1.2 状态闭环用例
| ID | 用例 | Arrange | Act | Assert |
|----|------|---------|-----|--------|
| S1 | 状态→视图→重绘闭环 | `StateStore` 挂载 Counter，含 count | dispatch `Inc` | store 内状态更新、视图缓存刷新、发布 dirty（若暴露） |
| S2 | 多实例隔离 | 两个独立 Counter 实例 | 对实例 A dispatch Inc | 仅 A 状态变，B 不变 |

### 1.3 WidgetRegistry 用例
| ID | 用例 | Arrange | Act | Assert |
|----|------|---------|-----|--------|
| R1 | 注册后查询到 | `WidgetRegistry::new()` | `register("accordion", spec)` → `get("accordion")` | 返回 Some(匹配类型) |
| R2 | 重复注册报错 | 已注册 "accordion" | 再 `register("accordion",..)` | 返回 `Err(DuplicateId)` |
| R3 | 查未注册 | 空注册表 | `get("nope")` | `Err(NotFound)` 或 None |
| R4 | 空名拒绝 | 新注册表 | `register("",..)` | 返回错误/拒绝 |

### 1.4 WidgetNode 用例
| ID | 用例 | 判据 |
|----|------|------|
| N1 | WidgetNode 包裹组件+状态，可构造 & 持有 WidgetId | `WidgetNode{id, spec, state}` 可正常构建，id 原子增 |
| N2 | 节点 view 委托 spec.view | 调 node.view() 与 spec.view() 一致 |

## 2. 状态 diff / snapshot（Patch 应用正确性）

**目标**：`diff` 生成正确 `Patch`；`apply_patch` 应用后状态收敛；snapshot 往返一致。

### 2.1 diff 用例
| ID | 用例 | Act | Assert |
|----|------|-----|--------|
| P1 | no-op diff | `diff(old,old)` | 返回空 Patch 列表 |
| P2 | 单属性变更 | 改一个 prop | 生成 1 个 Patch，含正确 key，old→new 值 |
| P3 | 新增节点 | 在 children 加一个 widget | 生成 insert Patch |
| P4 | 删除节点 | 移除一个 widget | 生成 remove Patch |
| P5 | 节点顺序变化 | child 顺序调换 | 生成 move/reorder Patch（或等价语义） |
| P6 | 值类型不变时 diff 为空（int 同值） | 同值新 form | 空 Patch |

### 2.2 apply_patch 用例
| ID | 用例 | Act | Assert |
|----|------|-----|--------|
| A1 | 应用属性变更 | 对状态应用 prop 变更 Patch | 状态属性更新为 new值 |
| A2 | 应用 insert | 对状态应用新增节点 Patch | children 多一个节点 |
| A3 | 应用 remove | 对状态应用删除 Patch | children 少一个节点 |
| A4 | 空 Patch 应用幂等 | 对状态应用空列表 | 状态不变 |
| A5 | diff→apply 往返收敛 | 任取 old,new → `diff` → `apply(new_state, patches)` | new_state 与 new 等价（深度一致） |

### 2.3 snapshot 用例
| ID | 用例 | Act | Assert |
|----|------|-----|--------|
| SN1 | snapshot 可序列化 & schema 稳定 | 建 Snapshot | `schema_name`/`schema_version` 返回稳定值（DummyState=0/"dummy"） |
| SN2 | snapshot 往返 | `snapshot` → 反序列化 | 与源状态等价 |
| SN3 | SchemaMigration 兼容 | 旧版本 → `migrate` | 得到新版状态，字段补齐 |
| SN4 | 空状态 snapshot | 空 StateStore | snapshot 无 panic，字段默认 |

## 3. 布局（Taffy 集成：LayoutStyle → Taffy Style）

**目标**：`LayoutStyle` 正确映射到 `taffy::Style`；`LayoutEngine.compute_layout` 对已知约束返回预期尺寸/位置。

### 3.1 LayoutStyle→Taffy Style 映射用例
| ID | 用例 | Act | Assert |
|----|------|-----|--------|
| L1 | flex_direction 映射 | `LayoutStyle{flex_direction: Column}` | Taffy style.flex_direction==Column |
| L2 | align/justify 映射 | `align_items: Center`, `justify_content: SpaceBetween` | taffy 对应字段匹配 |
| L3 | 尺寸映射 | `width:100.0,height:50.0` | taffy.size=Size{width:100,height:50} |
| L4 | margin/padding 映射 | 设 4 边 margin/padding | taffy.margin/padding 匹配 |
| L5 | gap（container）映射 | 设 `gap` | taffy.gap 匹配 |
| L6 | 默认值兜底 | 全默认 LayoutStyle | taffy 为 Taffy Style::default() 等价，无 panic |

### 3.2 LayoutEngine 计算用例
| ID | 用例 | Act | Assert |
|----|------|-----|--------|
| CE1 | 单节点已知约束 | 一个固定 size 节点 + `compute_layout(root, avail)` | 返回 `LayoutResult`，size 与输入一致、position=origin |
| CE2 | 层叠（子节点） | 容器 + 子节点 | 子节点布局结果含相对偏移，父含总尺寸 |
| CE3 | 空树 | `compute_layout(empty)` | 空结果或默认，无 panic |
| CE4 | 重复 compute 幂等 | 同输入跑两次 | 两次结果一致 |

## 4. 边界 / 负向用例（三域通用）

| ID | 用例 | 判据 |
|----|------|------|
| E1 | 空 children | view/diff/layout 均不 panic |
| E2 | 极值尺寸（0 与 f32::MAX） | measure/layout 处理 0/无限约束正确 |
| E3 | 类型不匹配 prop | diff 对不同类型值（Int vs Str）生成变更 Patch，不 panic |
| E4 | 非法输入（负 margin、负 gap） | 映射/布局不 panic，行为确定（clamp 或拒绝） |
