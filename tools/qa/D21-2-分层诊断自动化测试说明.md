## 一、核心：脚本能"判断问题在哪"（零 LLM / 零 vision）

`rgui_input_test.py` 内置 **detect_layer(log_snapshot, case) -> (fail_layer, evidence, status_map)**，按 **L1→L5 顺次检查，首个失败层 = 诊断结论**，全部为确定性日志信号匹配（无大模型、无视觉判断）：

| 层 | 名称 | 信号 | 失败含义 |
|---|---|---|---|
| L1 | 注入层 | CG加载 / AX trusted | 脚本环境问题（未授权/库缺失） |
| L2 | 窗口层 | `[mouse-event] left-press at logical=(x,y)` / `[focus] Tab` | winit 未处理事件 |
| L3 | 命中层 | `[hit] id=1` / `id=2` / `id=none` | hit_test 命中错误组件 |
| L4 | 动作层 | `[action] toggle` / `badge_click(count=N)` / `[focus] Some(id)` | 组件状态未更新 |
| L5 | 功能层 | 二次注入持久（toggle 往返 / badge count 递增 / focus 移动） | 状态不持久/不可往返 |

## 三、关键实现要点（D21-2 实测校准）

1. **CGPoint 按值传递**：`CGEventCreateMouseEvent.argtypes = [void*, uint32, CGPoint, uint32]`（**不是指针**——传指针读到寄存器垃圾 0,0/nan，鼠标点击无效，这是 D21 首版鼠标不通的根因）。
2. **坐标单位 = 全局 point**：`screen_point = 窗口bounds左上(point) + 标题栏高 + rect中心(逻辑point)`。窗口 bounds + 标题栏高用 **Quartz CGWindowList 运行时实测**（非日志估算）。CGEvent 鼠标与 CGWindowList 同 point 体系。
3. **窗口激活/置前**：`activate_app(pid)`（NSRunningApplication.activate）+ `raise_window(pid)`（osascript AXRaise）——窗口必须最前端，否则点击落在遮挡窗口。
4. **`CGEventSetIntegerValueField` 必须定义 argtypes**（Shift+Tab 用）：缺失会导致 segfault（D21-2 修）。
5. **预检 fail-fast**：注入前 AX trusted / CG 加载 / 窗口定位，失败 → exit 2（区分"脚本环境问题 vs 产品 bug"）。
