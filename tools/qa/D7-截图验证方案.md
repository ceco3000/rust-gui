## 6. 风险与对策

| 风险 | 对策 |
|------|------|
| 窗口不在前台（被其他 app 遮挡） | 截图前用 `osascript` 激活 dev 窗口（或 dev 提供激活方式）；否则在全屏截图中用 vision 定位目标窗口 |
| dev 窗口内容小、需局部放大 | vision_analyze 支持 region 裁剪，可 zoom 定位 |
| 交互无法自动化 | 至少截"窗口可见"静态图（用户要求 a）；交互对比尽可能做，做不了则如实说明 |
| 辅助功能权限缺失 | 已规避（不依赖窗口 ID）；若后续需精确窗口截取，需用户授予 Terminal/Hermes **辅助功能**权限 |
