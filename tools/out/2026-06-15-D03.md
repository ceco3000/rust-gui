## 变更摘要

将 `IpcChannel` 从仅有 `new()` 的空存根升级为完整的 IPC 传输层实现：

- 实现 **长度前缀帧协议**（4 字节 LE 长度 + postcard 负载）
- **`send(&mut self, msg: &IpcMessage) -> Result<(), IpcError>`**——序列化消息并写入 stream
- **`recv(&mut self) -> Result<IpcMessage, IpcError>`**——读取长度前缀，反序列化消息
- **`MAX_MESSAGE_SIZE = 64 MiB`** 上限，防止恶意长度声明导致 OOM
- 错误映射函数 `map_write_error`/`map_read_error` 精确区分对端断开与一般 I/O 错误

## 平台支持

- **Unix (macOS/Linux)**：完整实现，使用 `UnixStream` + 长度前缀帧协议
- **Windows**：存根实现，`send()`/`recv()` 返回有意义的错误消息（阶段 2 预留）

## API 增强

- `IpcMessage`：添加 `#[non_exhaustive]`（未来兼容性）
- `IpcError`：添加 `#[non_exhaustive]` + `PartialEq` derive
