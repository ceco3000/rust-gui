## 核心类型

| 类型 | 说明 |
|------|------|
| `FileChangeKind` | 文件变更分类枚举（Style/rgui / Structure/rgui / Rust/rs / Other） |
| `FileChangeEvent` | debounce 合并后的单次变更事件（path + kind） |
| `FileWatcher` | 文件系统监控器，封装 `notify::RecommendedWatcher` + mpsc 通道 + debounce 逻辑 |

## 主要方法

| 方法 | 说明 |
|------|------|
| `FileWatcher::new(config)` | 创建监控器，递归监控 `config.watch_paths` |
| `check_changes()` | 轮询 debounce 合并后的变更列表 |
| `flush()` | 强制刷新（忽略 debounce 窗口） |

## 关键设计决策

1. **无界 mpsc 通道**：notify 回调不应阻塞，文件系统事件不会爆炸式增长
2. **同路径去重**：`handle_event` 中通过 `retain` + `push` 实现，只保留最后一次变更
3. **仅处理 Create/Modify**：忽略 Remove 和元数据变更事件
4. **扩展名大小写不敏感**：`to_ascii_lowercase()` 处理后匹配
5. **watcher 字段保持存活**：`#[allow(dead_code)]` 标记，drop 即停止监控
