**日期**: 2026-06-15
**任务ID**: T01

## 实现概述

在 `rgui-state` crate 中新增 `TestHarness` 测试辅助结构体，提供「3 行创建测试环境」的快速测试能力。

## 设计依据

- D9 §9 测试辅助工具设计
- D9 原型设计：
  - `state_store: StateStore`
  - `registry: WidgetRegistry`
  - `new()`、`mount()`、`widget_count()`

## 实现细节

### 新增文件

- `rgui-state/src/harness.rs` — TestHarness 结构体、实现和单元测试

### 修改文件

- `rgui-state/src/lib.rs` — 添加 `pub mod harness` 和 `pub use harness::TestHarness`
- `rgui/src/lib.rs` — 添加 `pub use rgui_state::TestHarness` 显式 re-export

### TestHarness API

```rust
pub struct TestHarness {
    pub state_store: StateStore,
    pub registry: WidgetRegistry,
}

impl TestHarness {
    pub fn new() -> Self;
    pub fn mount<W: WidgetSpec>(&mut self, spec: &W, state: W::State) -> WidgetId;
    pub fn widget_count(&self) -> usize;
}

impl Default for TestHarness { ... }
```

### 测试覆盖

6 个测试用例，覆盖：
- 空 harness 创建
- Default trait 行为
- 单 widget 挂载（ID 分配 + 注册）
- 多 widget 挂载（ID 唯一性）
- 重复名称 panic 行为
- 3 行创建验收

## 技术决策

- **位置选择**: 放在 `rgui-state` 而非 `rgui` facade，因为需要调用 `StateStore` 的 `pub(crate)` 方法（`allocate_id`、`insert_persistent`）
- **WidgetTree 暂缺**: D9 原型包含 `widget_tree: WidgetTree`，但 `WidgetTree` 尚未实现，当前版本暂不包含
- **dispatch/run_frames 暂缺**: 这两个方法依赖 WidgetTree + EventRouter，留待后续任务补充
