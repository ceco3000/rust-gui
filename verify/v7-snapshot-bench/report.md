# V7: 状态快照性能基准

📅 2026-06-12 | 🖥️ macOS 15 (Apple Silicon) | Rust 1.92.0

## JSON 序列化/反序列化

| 场景 | 数据量 | 序列化 | 目标 | 反序列化 | 目标 |
|------|--------|--------|------|---------|------|
| TODO 应用 | ~5KB | **4.6 µs** | < 1ms | **11.0 µs** | < 1ms |
| CRUD 后台 | ~50KB | **6.4 µs** | < 10ms | **31.0 µs** | < 100ms |
| 压力测试 | ~500KB | **84 µs** | < 50ms | **464 µs** | < 500ms |

## postcard (二进制) vs JSON

| 场景 | JSON | postcard | 加速比 |
|------|------|---------|--------|
| serialize_todo | 4.6 µs | 1.9 µs | 2.4x |
| deserialize_todo | 11.0 µs | 8.5 µs | 1.3x |
| serialize_crud | 6.4 µs | 5.0 µs | 1.3x |
| deserialize_crud | 31.0 µs | 27.9 µs | 1.1x |

## 结论

✅ 全部通过。建议阶段 1 同时支持两种格式：postcard 用于快速重启，JSON 用于人类可读的时间旅行调试。
